### W9-impl 执行 Phase 3：惰性刷新 + 互斥 + 分组写语义 + disabled 全路径拒绝

- **Plan**：`ai-dev/plans/2026-08-14-2342-1-credential-oauth-flow-engine.md`（Phase 3 completed）
- **互斥载体（Phase 3 Decision 落地）**：DB 行级锁 `IEntityDao.lockEntity`（SELECT FOR UPDATE，javadoc 明示）+ 事务模板 REQUIRED，持锁完成"读 data → 刷新外呼 → 回写"全程；不选乐观 version（刷新外呼失败后的重读重试链路复杂度高于行锁）。写路径串行化范围：惰性刷新与 saveCredential 分组写共用 `engineUpdateInLock` 同一入口（新增 BiConsumer 扩展重载：元数据与 data 同一锁下 UPDATE 提交，消除两步写间的乐观锁版本竞争），互斥覆盖"刷新 vs 刷新"与"刷新 vs 人工保存"；非刷新取用不持锁可并发。
- **惰性刷新**：`getCredential` oauth2 分支——非临期直接返回（不持锁）；临期（now 距 expiresAt < 刷新窗口，类型级 refreshWindowSeconds 覆盖全局缺省 `nop.credential.oauth.refresh-window-seconds`=300）→ 锁下双重检查 → `OAuthTokenClient.refresh`（grant_type=refresh_token + clientId/clientSecret）→ 新 token 集回写（只写保留字段）→ 返回新明文。刷新失败 fail-closed（`ERR_OAUTH_REFRESH_FAILED` 包装 invalid_grant 等）；refreshToken 缺失且已过期 fail-closed（`ERR_OAUTH_REAUTH_REQUIRED`）。
- **disabled 全路径拒绝**：`loadActiveCredential` 接入 `assertOauth2NotDisabled`（oauth2 类型 status=disabled → `ERR_CREDENTIAL_DISABLED`，覆盖 getCredential/getCredentialData/mask/testCredential + engine 通道 = 发起/回调/刷新/取用全路径）；类型未注册容忍（一期语义零新增失败路径）；非 OAuth 类型维持仅 delFlag。
- **saveCredential 分组写 + typeList 裁剪**：oauth2 类型输入出现保留字段名拒绝（`ERR_CREDENTIAL_RESERVED_FIELD_INPUT`）；更新路径锁下保留字段原样保留 + 人工字段整包替换（未传即删）+ 元数据同锁更新；新建路径一期不变；`typeList` 对 oauth2 类型防御性裁剪保留字段。
- **验证**：`TestCredentialOAuthRefresh` 12/12：临期触发刷新恰一次（计数==1）+ 回写验证 + 窗口内再取用不刷新；非临期零调用；刷新失败 fail-closed 且 data 不变；过期无 refreshToken 抛 reauth；无 refreshToken 未过期返回现值；**4 线程并发取用临期凭证刷新端点计数==1 且全部线程同 token**；**并发"取用刷新 vs saveCredential"无丢失更新**（新 token + 新人工字段并存）；disabled oauth2 取用/脱敏拒绝；disabled 非 OAuth 仍可取（一期语义保持）；saveCredential 保留字段输入拒绝（GraphQL 驱动）；人工替换保留 token 集；typeList 裁剪。全模块 98/98 绿（一期回归 TestNopCredentialBizModel 15/15 + TestCredentialProviderImpl 13/13 零回归）。
