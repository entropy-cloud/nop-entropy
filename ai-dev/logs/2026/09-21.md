### nop-lint plan 03 预研：pattern CST 形态实验（java blob 实测）

- 为 SourcePatternCompiler（roadmap item 3）拟定编译规则，用临时 JUnit 探针实测 23 个 pattern 的 CST 形态（探针用后即删，本条为留痕）：
  - 裸表达式 pattern（`foo()`/`$A == $B`/`$VAR`/`0`）在 program 级产生**单子同跨度 ERROR 包装**；`class X { $$$ }` 类体与 `if (...) { $$$ }` 块体的裸 `$$$` 同为单子 ERROR 包装——转换期须全局剥离。
  - `throw new $$$` 产生**多子 ERROR**（无法剥离）→ 按 design 04 §8 P0 拒绝编译；等价可解析写法 `throw new $$$($$$)`。
  - 语句 pattern 尾部普遍有零宽 **missing unnamed `;`**（`throw ...`/`return null`），须丢弃；missing **named** 节点真实存在于 `void m(int) {}` 的 formal_parameter 内——转换期拒绝编译（fail-fast）。
  - `$OBJ.dao().$METHOD($$$ARGS)`、`class $C extends CrudBizModel { $$$ }`、`@BizMutation public $$$ $METHOD(...)`（design 01 §3.5 首例）均干净解析。
