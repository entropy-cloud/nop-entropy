### Key Design Decisions

- **存储/值分离（sidecar）**：accumulator-based state（Reducing/Aggregating/Appending）存 `SimpleAccumulator`/raw ACC，包装成 `TtlValue<T>` 会破坏 `(ACC) current` 类型转换 + fusion 逻辑 → 时间戳放 sidecar，value 始终 raw
- **per-state sidecar 而非全局**：不同 state 可有不同 TTL duration，全局 sidecar 会因 key 表示在不同 state 间碰撞
- **intrusive modification 而非 wrapper/decorator**：`MemoryStateSerDe`/`RocksDBSnapshotSerDe` 用 `instanceof` 分发，wrapper 会破坏分发
- **restored entry fresh window**：`StateTtlConfig` 不持久化；restore 后 sidecar 空，restored entry 首次访问按 `OnCreateAndWrite` 给 "now" 时间戳（不因 sidecar 未持久化而立即过期）；`getState(liveDescriptorWithTtl)` rebind `TtlContext`
- **writeEviction**：容器型 state（Map/List/Reducing/Aggregating）write 前 evict 过期项，防止 `computeIfAbsent`/read-modify-write 混入 stale 数据
- **RocksDB native compaction filter 裁定延后**：执行期核实 `rocksdbjni` 9.11.2（亦见于 7.9.2）未暴露纯 Java compaction-filter 回调——`AbstractCompactionFilter` 仅有 protected native 构造器无 `filter()` 可覆盖。改纯 Java `cleanupExpiredEntries()` sweep 作语义等价后台清理。详见 plan Deferred 与 design §12.8
