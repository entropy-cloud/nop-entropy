### gen-aop 代理编译 classpath 根治——chronic 家族清零，平台首次全绿 clean install（plan 2450）

- **用户质询触发的研究**："gen-aop 怎么会有问题，仔细研究一下执行原理"。结论：执行原理（编译后扫描 .class → 生成 `Xxx__aop.java` → 内存补编译）没问题，**断在补编译的 javac classpath**：`JdkJavaCompiler.getDefaultClassPaths()` 读 `java.class.path`，而 exec:java 进程内该属性 = 仅 `.mvn/wrapper/maven-wrapper.jar` 一个文件（`help:evaluate` 实证）——代理源码里所有项目类型"找不到符号"。
- **在位探针实证**（临时补丁跑真实失败现场，用后即还原、绝不提交）：exec:java 运行期 TCCL = 普通 `java.net.URLClassLoader`，URLs 含 target/classes + 全部依赖——真实 classpath 一直挂在 TCCL 上，只是从未传给 javac。
- **flakiness 真相**：`saveCode` 内容去重——失败构建已落盘代理源码，后续构建跳过编译"假绿"但代理 class 从未产出（tcc-dao target/classes 零 Proxy class 实证）；`clean` wipe 后必现失败。chronic 家族"时有时无"由此而来。
- **近因考古（审查 M1 实证）**：TCCL 收集逻辑**原本存在**，commit b8157644a6（plan 2349，10-09）以"实测恒走回退"为由删除——该实测只在 surefire 上下文成立（AppClassLoader 非 URLClassLoader）；exec:java 下 ClassRealm 恒真。plan 2450 显式推翻该裁定并重写遗留注释。
- **修复**：`getDefaultClassPaths()` 遍历 TCCL 父链收集 URLClassLoader 的 URL → File 解码 + 存在性过滤 + 去重，空则回退 java.class.path、非空则拼接兜底；新增 `TestDefaultClassPaths`（文件 URL + 目录 URL 收集、顺序保持、surefire 回退语义钉扎，2/2 绿）。验证命令必须前置 install nop-javac（exec:java 经**插件依赖链**从本地 repo 加载它，不经 reactor——审查 B1 实证）。

### 调查附记：nop-cli-core IChatService IoC 双候选根因（用户质询，诊断闭环，归 nop-ai 栈）

- **不是"两个同名定义"**：`IChatService` 一接口两实现——nop-ai-core 的基础实现（`$DEFAULT$nopChatService`，`ioc:default="true"`）+ nop-ai-gateway 的故障转移装饰器（`nopChatServiceFailoverAdapter`，wrap 前者 + 熔断），设计正常。
- **gateway Bean 不是 test 阶段的**：装饰器是生产 Bean（failover 是生产能力）；但 nop-ai-gateway **作为 jar** 经 plan 2438 加的 test 依赖进入 cli-core 测试容器（dependency:tree 实证 `nop-ai-gateway:...:test`）——"test 阶段不应出现"的直觉部分成立。
- **真正搞错的**：`ioc:default="true"` 被误解了。beans.xdef:218 明文：**ioc:default = 自动加 condition-on-missing-bean 条件**（等价 Spring `@ConditionalOnMissingBean`），**不是**按类型解析优先——后者是独立的 `primary` 属性。后果：gateway 在 classpath 时两个 IChatService Bean 同时注册、无 primary → `resolveBeanByType` 必抛 multiple-bean（且哪边被 condition 跳过还取决于 beans.xml 加载顺序——`beans/` 按字典序先于 `gateway/beans/`，脆弱）。
- **修法建议（归 nop-ai 栈决策）**：装饰器去掉 `ioc:type`（改按名注入，failover 显式 opt-in）——最小且确定性；或装饰器标 `primary="true"` 且核心 Bean 退出 by-type 候选。
