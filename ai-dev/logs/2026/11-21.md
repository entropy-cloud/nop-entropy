- **P2**：checkout/-b/-c（Already on 契约）、switch、reset soft/mixed/hard、clean -n/-f/-fd（untracked 目录折叠语义对齐原生）、restore、rm、mv（JGit 无 move 命令——Files.move+index 双写实现）、stash push/list/pop。
- **worktree**：API list/add/remove/prune + CLI 全套；双向对照测试双向绿（真实 git 建→nop 读删；nop 建→真实 git 识别+在 worktree 内 commit 验证共享 refs）；commondir 逐字节 `../..

- **P3**：init -b、remote add/-v/set-url/rm；push（refspec+-u，upstream 配置落 branch.remote/merge）/fetch/pull（fetch+ff merge）/clone（本地 file 远程 clone→commit→push→fetch/pull 往返绿）；merge ff/no-ff（冲突原生风格报错）、rebase、cherry-pick（单 commit，冲突报错）。

## nop-git Wave 3 落地（plan 2578：权限策略引擎，roadmap items 12-17）

- **引擎**：`io.nop.git.policy` 包（IGitOperationRequest/GitVerdict 偏序 DENY>REVIEW>ALLOW/IGitPolicyEngine/DefaultGitPolicyEngine/GitPolicyLoader/GitPolicyConfig/GitRequests）。snakeyaml 2.2（bom 唯一声明）。分层加载（项目 .nop-git/policy.yaml → ~/.nop-git/policy.yaml → 内置默认）+ strict 合并（标量取最严、规则并集、三操作集跨层互斥——review/deny 显式层从合并 allow 中移除，实测踩坑：builtin allow 含 add 会吞掉用户层 review）。
- **五维评估**按 design 03 §三钉死语义：scope 命中非 deny fall-through；review 累积先于 allow 白名单（有意语义）；operations.review 集合显式 → REVIEW；default_effect 兜底。glob 走 gitignore 语义（无斜杠 pattern 匹配 basename）；路径 canonicalize 以 repo root 为基准（../ 规范化），CLI 归一化/提取收敛在 GitRequests 单实现。
- **review 通道**：NOP_GIT_REVIEW_APPROVED / 交互 stdin / 超时降级 deny；session 级批准缓存（CLI+门面同引擎双重裁决不重复提示）；review prompt 输出到 stderr（stdout 是 AI 工具解析的 git 输出）。
- **observe/enforce + 审计**：observe 全放行 + hypotheticalEffect；JSON Lines 单行一次写入含 outcome（denied/review-denied/ok/error），deny 契约 `fatal: policy denied: <原因>` exit 1。
- **双拦截点**：CLI policyGuard（argv→归一化 request，deny 即审计+退出；observe 跳过阻断交门面审计）+ 门面 guarded()（每公开方法执行前裁决、单行审计）；同一引擎实例经 CliContext.openRepo 贯穿。
- **测试**：core 引擎级 14 例（五维矩阵/绕过尝试 -f、-fd、--force-with-lease=x、路径遍历/refspec、三层合并、畸形配置 fail-loud、审计字段全集、observe/enforce、inactive 零污染）+ cli 入口 E2E 5 例（enforce deny 契约行、default deny、observe、无 policy 零行为变化、.env 路径拒绝）全绿；Wave 2 parity/golden/smoke 回归不红（引擎非激活裁定保证）。
- **owner doc reconcile**：design 03 修 §二 option_rules 示例改规范 flag、§三钉死偏序/fall-through/review-vs-allow 顺序 + 新增引擎非激活裁定与 outcome 回填协议 + `-d` 按命令定表。
- 已知边界：push/reset/branch -d 等 Wave 4 子命令的裁决已到引擎级单测，入口级拦截随 Wave 4 扩表接入（plan 2578 Deferred 显式裁定）。
