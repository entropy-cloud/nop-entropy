### 文件编辑策略设计文档编写（含重命名）

- **做什么**：调研 Codex / Pi Agent / DeepSeek Harness 三个主流 AI 编程助手的文件编辑机制，提炼为 Nop 平台的多策略文件编辑工具设计方案
- **调研范围**：
  - Codex `apply_patch`：自定义 patch 格式 + 4 级递进模糊匹配（精确→rstrip→trim→Unicode 归一化），行级操作，支持 add/delete/update/move
  - Pi Agent `edit`：精确文本替换 `{oldText, newText}`，2 级匹配（精确 + NFKC+Unicode 标准化），IDE 风格
  - DeepSeek Harness `edit`：纯精确字符串匹配（`split/join`），无模糊容错，CAS 版本锁并发保护
- **产出**：`ai-dev/design/nop-ai-agent/nop-ai-tool-file-edit-strategies.md` — 4 种独立编辑策略的设计文档，各保留原始系统的完整算法，作为可插拔策略供 Agent 配置选择
- **策略命名**（按行为命名，不按来源项目）：write / line-patch / fuzzy-replace / exact-replace
- **设计结论**：
  1. 4 种策略独立实现、独立注册，不做算法融合
  2. 各策略保留原始匹配算法（line-patch 4 级 / fuzzy-replace 2 级 / exact-replace 纯精确）
  3. 通过 Agent 配置的 `toolNames` 列表选择启用哪些策略
  4. 预设：minimal(write) / default(write+fuzzy-replace) / strict(write+exact-replace) / full(全部)

### 文件读取策略设计文档编写（含重命名）

- **做什么**：调研三个项目的文件读取工具实现，提炼为 Nop 平台的多策略文件读取工具设计方案
- **调研范围**：
  - Codex：无专用 read 工具，通过 `exec_command` shell 执行 `cat`/`head`/`sed` 等命令；截断使用 HeadTailBuffer（1 MiB，50/50 head/tail 分割）+ token 预算（默认 10K）
  - Pi Agent `read`：纯文本读取，**不返回行号**；截断 2000 行 / 50KB 先到先停；支持图片（base64 + 自动缩放至 2000x2000）
  - DeepSeek Harness `read`：**返回行号**（`N: content` 格式），结构化输出（lines[] + totalLines）；三重截断（2000 行 / 50KB / 单行 2000 字符）；≥10MB 流式读取；`str_replace_editor view` 提供 `cat -n` 风格行号（6 字符右对齐）+ 目录查看
- **产出**：`ai-dev/design/nop-ai-agent/nop-ai-tool-file-read-strategies.md` — 4 种独立读取策略的设计文档，作为可插拔工具供 Agent 配置选择
- **策略命名**：shell-read / plain-read / numbered-read / cat-view
- **设计结论**：
  1. 4 种策略独立实现，不做接口统一
  2. 行号是核心差异：shell-read 无行号 / plain-read 无行号 / numbered-read 有行号 / cat-view 有行号
  3. 各策略保留原始截断策略和大文件处理方式
  4. 预设：minimal(shell-read) / default(plain-read) / strict(numbered-read) / deepseek(numbered-read+cat-view) / full(全部)
- 验证：`node ai-dev/tools/check-doc-links.mjs --strict` — 新文件无断链引入
- Doc-sync: `ai-dev/design/nop-ai-agent/nop-ai-tool-file-read-strategies.md` 新建；`docs-for-ai/` 暂不更新
