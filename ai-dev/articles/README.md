# articles — 技术文章

本目录存放面向公开传播的技术文章（论述文、评析文），区别于 `analysis/`（调研/对比/评估报告）。

## 与相邻目录的区别

| 目录 | 用途 | 形式 |
|------|------|------|
| `articles/` | 技术论述与评析文章 | 成文、可对外发表、有观点与论证 |
| `analysis/` | AI 单方面调研、对比、评估 | 决策参考，结论可被推翻 |
| `design/` | 架构决策与使用契约 | source of truth |
| `logs/` | 每日开发记录 | 短期上下文 |

## 目录结构

```
articles/
├── README.md               # 本文件
└── YYYY-MM/                # 按月归档
    └── YYYY-MM-DD-<slug>.md
```

## 约定

- 文件名以 `YYYY-MM-DD` 开头，按 `YYYY-MM/` 子目录归档
- 文章头部包含元信息：日期、关联论文/参考文档、摘要
- 引用外部论文时，尽量关联到 `ai-dev/references/` 下的本地副本
- 公式保留 LaTeX 或 Unicode 数学符号
