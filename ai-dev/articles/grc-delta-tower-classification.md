# 差量之塔有多深：二阶差量的 crossed module 结构与 patch/lens 定理的导入

> 本文是 GRC 形式化系列第三篇。前文：[《差量传输理论：生成器演算》](../../ai-dev/analysis/2026-08/2026-08-26-grc-delta-transport-theory.md)、[《生成器看见了什么》](./grc-maximal-transportable-substructure.md)。本文回答两个前文未触及的问题：差量的差量递归塔是否无限加深？patch/lens 理论的哪些定理可以在 GRC 局部直接使用、哪些结构是它们没有的？

## 引言

前文的共轭定理给出一个令人不安的事实：二阶差量（对差量的修改）穿过既有差量链的代价是共轭 `δ⁻¹εδ`。这引出一个自然问题：三阶差量（对"差量的差量"的修改）是否引入全新的第三层机制？四阶呢？本文证明：**不会**。可逆型差量空间中，塔的代数深度恰好是 2——第一层是结构 S 与差量 D，第二层是 D 的自作用，再往上全部折叠回前两层；塔的整体结构恰好是差量群的**内自同构 crossed module**，也就是一个 **2-group**；所有混合链（差量与差量的差量交错组合）有规范形，且不同归约顺序一致（confluence）。

同一框架也精确回答了"patch/lens 定理在 GRC 局部是否直接可用"：是的，而且对应关系可以逐条写出——Darcs 的 merge 在可逆型空间退化为可静态计算的差异差量公式 `d₁⁻¹⊗d₂`，**冲突的出现等价于逆的缺失**（Nop 的 tombstone 与 Darcs 的 conflictor 是同一现象在两种空间的编码）；delta-conservative 的转换器自动导出**良态 lens**（定理 D；逆问题——任意良态 lens 是否都来自 delta-conservative 生成器——本文未证），且 lens 理论中的"补语"（complement）在 GRC 中就是上游结构本身。

## 一、预备

沿用前文记法：差量 actegory `(S, D, ⊕, ⊗, ≈, 1)`，公理 A1-A4（含 ⊕ 第一参数同余）。本文在**可逆型**（每个 d 有逆 d⁻¹）+ 忠实（逐点）空间中工作。前文已证：

- **定理 5（自作用）**：`(D, D, ⊕₂:=⊗, ⊗₂:=⊗, ≈, 1)` 自身是差量 actegory——"差量的差量"无需新机制；
- **定理 6（共轭）**：二阶生成器 `R_δ(d) := d⊗δ`（追加 δ）恒可传输，其唯一传输是 `T_{R_δ}(ε) = δ⁻¹⊗ε⊗δ`（共轭）；`L_δ(d) := δ⊗d`（前插）的传输恒为 id；
- **推论 6.1（插链 = 共轭）**：`(Δᵢ⊗ε)⊗Δᵢ₊₁ ≈ (Δᵢ⊗Δᵢ₊₁)⊗(Δᵢ₊₁⁻¹⊗ε⊗Δᵢ₊₁)`；
- **引理 0**：`s ⊖ s ≈ 1`；`(d₁⊗d₂)⁻¹ ≈ d₂⁻¹⊗d₁⁻¹`；`s₂ ≈ s₁⊕d ⟺ s₁ ≈ s₂⊕d⁻¹`（可逆型时）；**引理 1**：`a≈a' ⟹ a⊖b ≈ a'⊖b`。

再固定两个记号。**右共轭作用**（二阶传输的产物）：

```text
δ ⊳ ε := δ⁻¹ ⊗ ε ⊗ δ
```

**左共轭作用**（便于写 crossed module 公理）：

```text
b(δ)(ε) := δ ⊗ ε ⊗ δ⁻¹
```

两者关系：`δ ⊳ ε = b(δ⁻¹)(ε)`。下文的公理与定理均用 `b` 陈述（标准的 crossed module 约定）。

## 二、塔的分类定理

### 定理 A（二阶塔 = 内自同构 crossed module）

设 (S, D, ⊕, ⊗, ≈, 1) 是可逆型 + 忠实的差量 actegory。则三元组

```text
( ∂ := id_D : D → D,   b : D → Aut(D),   b(δ)(ε) := δ⊗ε⊗δ⁻¹ )
```

是**内自同构 crossed module**。两条 crossed module 公理分别核对：

1. **∂ 与作用交织**（标准形式：`∂(ⁿm) = n ∂(m) n⁻¹`）：`∂(b(δ)(ε)) ≈ δ ⊗ ∂(ε) ⊗ δ⁻¹`。因 `∂ = id`，两端同为 `δ⊗ε⊗δ⁻¹`，平凡成立——该公理在此退化为"作用就是共轭"这一事实本身（与第 2 条的传输读法同一内容，见下）。
2. **Peiffer 恒等**：`b(∂(ε))(ε') ≈ ε ⊗ ε' ⊗ ε⁻¹`。因 `∂ = id`，左端即 `b(ε)(ε') = ε⊗ε'⊗ε⁻¹`。**GRC 读法**：左共轭作用 `b(ε)` 恰是生成器 `R_{ε⁻¹}`（追加 ε⁻¹）的传输——定理 6(b) 的等价形式（`T_{R_{ε⁻¹}}(ε') = (ε⁻¹)⁻¹⊗ε'⊗ε⁻¹ = ε⊗ε'⊗ε⁻¹`）。

**证明**。第 1 条按定义逐字成立（∂ 为恒等）。第 2 条展开即 `ε⊗ε'⊗ε⁻¹ ≈ ε⊗ε'⊗ε⁻¹`。∎

这个定理的证明平凡得近乎同义反复——这恰恰是 crossed module 理论的标准事实：**任何群的 `(G, id, 共轭)` 都是 crossed module（内自同构 crossed module），而 crossed module 与 2-group（严格单对象 2-范畴，1-、2-态射均可逆）是等价数据**（Whitehead 1949 引入 crossed module；与 2-group 的等价标准归因 Brown–Spencer 1976 / Loday 1982）。本文的非平凡性在于**识别**：GRC 二阶塔的全部代数内容（自作用 + 共轭传输）不多不少正是这个 crossed module；塔的结构上限由此被确定。

### 定理 B（塔深 = 2，混合链有规范形）

1. **塔稳定**：自作用的自作用就是自作用——`(D, D, ⊗, ⊗, ≈, 1)` 再次做自作用得到完全相同的 actegory；三阶"差量的差量的差量"的元素仍是 D 的元素，其传输仍是共轭（元素仍属 D）。
2. **规范形与 confluence**：任意混合链（一阶差量 dᵢ 与二阶差量 εⱼ 交错组合，如 `((d₁⊗ε₁)⊗d₂)⊗ε₂`）都归约为单一差量；不同归约顺序的结果 ≈ 相等。

**证明**。

(1) 直接：自作用构造只把载体从 S 换成 D、作用从 ⊕ 换成 ⊗，而 `(D, D, ⊗, ⊗)` 的自作用仍落在 `(D, D, ⊗, ⊗)`（D 与 ⊗ 不变）。∎

(2) 归约规则只有一条：**右推共轭**（推论 6.1）。把每个夹在 `dᵢ` 与 `dᵢ₊₁` 之间的 ε 右移越过 `dᵢ₊₁`，代价是共轭 `dᵢ₊₁⁻¹⊗ε⊗dᵢ₊₁`；迭代右移直到所有 ε 都排在链尾。此时链形如

```text
(⊗ᵢ dᵢ) ⊗ (δ₁ ⊗ δ₂ ⊗ …)
```

其中 δⱼ 是各 εⱼ 的共轭产物——整个混合链成为一个单一差量。confluence：需要验证不同右推顺序结果一致。两步即可：

- **相邻二阶差量交换**：把 ε₁、ε₂ 依次右移越过 d，与把 ε₁⊗ε₂ 一次右移越过 d 结果相同——`(d⁻¹⊗ε₁⊗d)⊗(d⁻¹⊗ε₂⊗d) ≈ d⁻¹⊗ε₁⊗ε₂⊗d`（A3 结合律与 `d⊗d⁻¹ ≈ 1`）。
- **跨多个一阶差量**：ε 先越 d₁ 再越 d₂ 的两次共轭 `d₂⁻¹⊗(d₁⁻¹⊗ε⊗d₁)⊗d₂ ≈ (d₁⊗d₂)⁻¹⊗ε⊗(d₁⊗d₂)` 与一次越过 `d₁⊗d₂` 相同（A3 + 引理 0 的逆公式 `(d₁⊗d₂)⁻¹ ≈ d₂⁻¹⊗d₁⁻¹`）。

两步骤穷尽所有交错可能，故 confluence 成立。（形式化层面：终止性显然——每步右推严格减少"左侧存在二阶差量的一阶差量"的反演数；上述两步恰好覆盖全部临界对，由 Newman 引理收紧为严格 confluence。）∎

**解释**：塔深定理给出主文章 §5"差量的差量仍然是普通差量"的**上界**——递归没有无限加深，两层的代数结构（2-group）是上限；三阶及以上的修改在元素层和传输层都折叠回前两层。工程含义：差量打包/版本管理的工具链**只需要两层机制**（差量 + 共轭传输），不需要第三层抽象。

**树差量（不可逆）对照**：塔在不可逆空间不满足 2-group（无逆 ⇒ 无共轭双射 ⇒ 无 crossed module）。此时"右推"规则退化：删除/替换只能以 tombstone 证据表达，混合链的归约规则正是 proof-v2 §6.3 的 tagged 规范化组合表（`Remove⊗Merge → Replace(Apply(empty_p, Merge(μ,δ)))` 等 16 条规则）。即：**proof-v2 的组合表就是无逆差量空间的"弱 coherence 数据"——crossed module 的 Peiffer 恒等在不可逆情形的逐坐标编码**。此为分类学对照陈述，非本文定理。

## 三、patch/lens 定理的导入

### 定理 C（merge 导入：可逆型空间冲突消解）

设 (S, D, …) 可逆型 + 忠实。对任意基点 s 与任意 d₁, d₂ ∈ D，两分支 `s⊕d₁` 与 `s⊕d₂` 的**差异本身就是一个差量**，且精确可算：

```text
(s⊕d₂) ⊖ (s⊕d₁) ≈ d₁⁻¹ ⊗ d₂          （从分支 1 到分支 2 的差量）
(s⊕d₁) ⊖ (s⊕d₂) ≈ d₂⁻¹ ⊗ d₁          （从分支 2 到分支 1 的差量）
```

两差异差量**互为逆**（引理 0 的逆公式：`(d₁⁻¹⊗d₂)⁻¹ ≈ d₂⁻¹⊗d₁`）。注：此处 ⊖ 的存在性由显式构造给出，无需强可逆假设；唯一性由逐点忠实给出。这恰是 Darcs merge 的 group 实例：Darcs 的 `merge(p,q)` 要解析的核心内容——从 p 结果到 q 结果的补差量——在可逆型空间中就是显式公式 `d₁⁻¹⊗d₂`——**merge 恒存在、无冲突、可静态计算**。因此 Darcs 意义上的"冲突"在可逆型空间中根本不会出现：任意两分支相互可达，分歧被差量本身吸收。

**证明**。`(s⊕d₁) ⊕ (d₁⁻¹⊗d₂) ≈ s⊕(d₁⊗(d₁⁻¹⊗d₂)) ≈ s⊕d₂`（A2、A3、逆、A1）；由 ⊖ 唯一性（逐点忠实）得 `(s⊕d₂)⊖(s⊕d₁) ≈ d₁⁻¹⊗d₂`。对称式同理。∎

**冲突 ⇔ 逆缺失（对照陈述，非定理）**：在不可逆空间（tree-delta），`(s⊕d₂) ⊖ (s⊕d₁)` 依然存在（强可逆：取 `Replace`），但**一般不唯一**（tree-delta 仅全局忠实、不逐点忠实，见前文 §1.2）且**无法表达为可逆的差量组合**——删除部分只能以 tombstone 记录（proof-v2 的潜在空间）。因此：**Darcs 的 conflictor（表示冲突的复合 patch 类型）与 Nop 的 tombstone（保留删除证据的潜在节点）是同一现象的两种编码——merge 差量中存在"不可逆的减"时如何保存不能被丢弃的证据**。可逆型空间中这种证据自动由逆给出（`d₁⁻¹⊗d₂` 就是证据），无需专门构造——这解释了为什么 group-like 运行时空间（Cordis）可以"卸载即还原"，而编译期树差量空间必须维护潜在证据。

### 定理 D（lens 导入：delta-conservative = 良态 lens）

设 `(G, T)` 是 delta-conservative 的态射（G 双射、G⁻¹ 保 ≈、T 在 ≈ 意义下双射且保 ≈），源空间强可逆，目标空间逐点忠实。**注**：目标强可逆自动成立——对任意 y₁, y₂ ∈ S_Y，取 sᵢ = G⁻¹(yᵢ) 与源中的差量 δ（s₂ ≈ s₁⊕δ），则 `y₂ = G(s₂) ≈ G(s₁⊕δ) ≈ G(s₁)⊕T(δ) = y₁⊕T(δ)`；故 `y ⊖ G(s)` 良定义（唯一性由目标忠实）。定义

```text
get := G : S_X → S_Y
put(s, y) := s ⊕ T⁻¹( y ⊖ G(s) )
```

则 (get, put) 满足 lens 的三条良态律：

1. **GetPut**：`get(put(s, get(s))) ≈ get(s)`。
2. **PutGet**：`put(s, y) ≈ s` 之后取 get 得 y：`get(put(s, y)) ≈ y`。
3. **PutPut**：`put(put(s, y₁), y₂) ≈ put(s, y₂)`。

**证明**。

(1) `get(put(s, get(s))) = G(s ⊕ T⁻¹(G(s)⊖G(s))) ≈ G(s ⊕ T⁻¹(1))`（引理 0：`x⊖x ≈ 1`）`≈ G(s⊕1) ≈ G(s) ≈ get(s)`。∎

(2) `get(put(s,y)) = G(s ⊕ T⁻¹(y⊖G(s))) ≈ G(s) ⊕ T(T⁻¹(y⊖G(s)))`（等变性）`≈ G(s) ⊕ (y⊖G(s)) ≈ y`（⊖ 定义 + 强可逆 + 忠实）。∎

(3) 用 PutGet 得 `G(put(s,y₁)) ≈ y₁`，故

```text
put(put(s,y₁), y₂) = put(s,y₁) ⊕ T⁻¹(y₂ ⊖ G(put(s,y₁)))
                   ≈ put(s,y₁) ⊕ T⁻¹(y₂ ⊖ y₁)
                   ≈ s ⊕ T⁻¹(y₁⊖G(s)) ⊕ T⁻¹(y₂⊖y₁)
                   ≈ s ⊕ ( T⁻¹(y₁⊖G(s)) ⊗ T⁻¹(y₂⊖y₁) )          （A2）
                   ≈ s ⊕ T⁻¹( (y₁⊖G(s)) ⊗ (y₂⊖y₁) )              （T⁻¹ 是同态：T 同态且双射）
                   ≈ s ⊕ T⁻¹( y₂ ⊖ G(s) )                          （G(s)⊕(y₁⊖G(s))≈y₁、y₁⊕(y₂⊖y₁)≈y₂，由 ⊖ 唯一性）
                   = put(s, y₂)
```

∎

**解释（补语 = 上游结构）**：lens 理论的标准分解是 `A ≅ B × C`（view × complement），put 的良态性依赖补语 C 的显式维护。定理 D 表明：**delta-conservative 情形下，补语就是上游结构 s 本身**，更新传播就是差量传输——GRC 中的 x-diff/传输机制自动承担了 lens 补语的维护义务。这是"GRC 包含 lens 局部"的精确形式：定理 D 给出的是 **get 双射**的情形——delta-conservative 生成器自动获得良态 lens 三律；非双射 get 对应 D_tr 非全时的部分结构（见前文 D_tr 理论），其与一般 lens 的完整对应未在本文证明。

## 四、搬运与识别（诚实边界）

本文四组结果的来源逐条标注：

| 结果 | 性质 | 说明 |
|---|---|---|
| crossed module 公理成立 | **搬运**（trivial 核对） | (G, id, conj) 是内自同构 crossed module 是 Whitehead 的标准事实 |
| 2-group 等价 | **搬运** | crossed module ↔ 2-group 是 Mac Lane/Whitehead 的经典对应 |
| 塔深 = 2、三阶折叠 | **识别**（GRC 独有） | 把塔（自作用 + 共轭传输）识别为 crossed module 后得到的结构性结论，patch/lens 无此问题域 |
| confluence（两步证明） | **识别 + 自证** | 右推共轭规则 + 两个交换论证是本文直接证明的，不依赖引用 coherence 定理 |
| merge 差异差量公式 | **搬运**（Darcs 的 group 特例） | `d₁⁻¹⊗d₂` 是 Darcs merge 补差量在可逆情形的显式展开，两分支差异互为逆 |
| 冲突 ⇔ 逆缺失 | **识别**（对照陈述） | conflictor/tombstone 同构观点，未形式化为定理 |
| 良态 lens 三律 | **搬运 + 逐条验证** | 定律是 Foster 的，验证是本文做的（PutPut 用到 T⁻¹ 同态性） |
| 补语 = 上游结构 | **识别**（GRC 独有） | lens 分解在 GRC 中的落地 |

结论：本文与系列前两篇一样，**不是新数学，而是新识别**——把现成的代数结构（crossed module、2-group、merge 互逆公式、lens 律）精确对齐到 GRC 的独有对象（差量塔、生成器、Delta VFS），使"塔有多深""冲突从哪来""补语是什么"从修辞问题变成可检验的定理陈述。真正的开放难题（细化存在性——对应 Koopman 本征函数的存在性；定量传输——对应谱收敛率）仍在前文声明的位置，未被本文触及。

## 五、工程推论

1. **差量治理只需两层机制**：版本化差量（一层）+ 共轭传输（二层）；工具链无需设计第三层抽象——塔深定理是上限保证。
2. **混合链规范化算法**：右推共轭 + 两步交换给出 confluence 保证的归约器，可作为差量包预合并（pre-merge）之外的"二阶预合并"依据。
3. **无冲突合并判据**：在可逆型子空间（如 Cordis 运行时、或 tree-delta 中不含删除的部分）上，任意两分支的差异差量恒可静态计算（`d₁⁻¹⊗d₂`），冲突只在删除/tombstone 出现时才可能发生——合并前可静态判定。
4. **设计器双向同步**：delta-conservative 的表象转换器自动获得良态 lens 三律，可视化设计器的模型↔视图同步（主文章 §7.5）可直接套用 put/get 机制。
