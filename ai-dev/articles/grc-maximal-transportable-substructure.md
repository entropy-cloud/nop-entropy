# 生成器看见了什么：GRC 的最大可传输子结构与差量世界的三分分解

> 本文是《差量传输理论：生成器演算》（`ai-dev/analysis/2026-08/2026-08-26-grc-delta-transport-theory.md`）的续篇，对应 Koopman 研究路径的第二阶段：从"提升是否存在"（定义性观察）推进到"提升在多大范围上存在"（不变子空间定理的对应）。

## 引言：当生成器不可传输时

前文证明了：生成器 G 可传输 ⟺ 变化导数 `∂G_s(d) = G(s⊕d) ⊖ G(s)` 与基点 s 无关。但大多数真实生成器并不可传输——规范化、投影、排序、默认值展开，都会让导数随基点漂移（例如 ℤ 上 `P(s)=s mod 2` 的导数在 d 为奇时随 s 交替）。可传输性是一个二元开关吗？还是有一个结构化的中间地带？

Koopman 理论给出了这个问题在动力学中的标准答案：**不是**。即使流在全体可观测量上不可对角化，仍然存在**最大的不变子空间**——在它上面算子线性、谱干净；其余可观测量构成残差。Koopman 研究纲领第二阶段的全部内容就是刻画这个子空间及其上的谱。

本文给出 GRC 的对应：对任意生成器 G 定义

```text
D_tr(G) := { d ∈ D_X : ∂G_s(d) 与基点 s 无关（≈ 意义下） }
```

——"G 能忠实传输的差量"。然后证明四件事：

- **定理 A（最大可传输子幺半群）**：`D_tr(G)` 含单位元、对组合 ⊗ 封闭，G 在其上可传输，且任何 `d ∉ D_tr(G)` 都不可能被任何传输覆盖（极大性）。
- **定理 B（群情形）**：差量空间可逆时 `D_tr(G)` 是子群，传输是群同态，`∂G_s(d⁻¹) ≈ T(d)⁻¹`。
- **定理 C（核与商分解）**：G 不可见的差量构成核 `Ker(T)`，传输诱导 `D_tr(G)/~_T ≅ Im(T) ≤ D_Y`——差量世界被 G 三分：不可见核、忠实传输的商、基点敏感残差。
- **定理 D（管道判别）**：多阶段生成链上，上游差量逐级存活判据与传输复合律。

工程结论：给定一条生成链，每个差量都属于三类之一——**死差量**（核内，下游完全不可见，可安全清除）、**稳定差量**（D_tr 内，下游效果与基线版本无关，升级安全）、**脆性差量**（D_tr 外，下游效果随基线漂移，升级迁移风险源）。

## 一、预备

沿用前文的记法。**差量 actegory** `(S, D, ⊕, ⊗, ≈, 1)`：⊕ 是 D 在 S 上的作用，⊗ 是差量组合（`d₁⊗d₂` 先 d₁ 后 d₂），公理：

```text
A1  1⊗d ≈ d ≈ d⊗1；s⊕1 ≈ s
A2  s⊕(d₁⊗d₂) ≈ (s⊕d₁)⊕d₂
A3  (d₁⊗d₂)⊗d₃ ≈ d₁⊗(d₂⊗d₃)
A4  s≈s' ⇒ s⊕d ≈ s'⊕d；d≈d' ⇒ s⊕d ≈ s⊕d'；⊗ 两侧同余
```

目标空间满足**强可逆**（任意 s₁,s₂ 之间存在差量 d 使 `s₂ ≈ s₁⊕d`）与**逐点忠实**（`s⊕d ≈ s⊕d' ⇒ d ≈ d'`，注意 tree-delta 仅全局忠实、不逐点忠实，见前文 §1.2/§10），于是**结构差** `⊖ : S×S → D`（≈ 意义下唯一）良定义：

```text
s₂ ⊖ s₁ := 唯一的 d 使 s₂ ≈ s₁⊕d
```

**变化导数**：`∂G_s(d) := G(s⊕d) ⊖ G(s)`。基点无关性：`d ∈ D_tr(G) ⟺ ∀s,s': ∂G_s(d) ≈ ∂G_{s'}(d)`。固定参考基点 s₀，记 `T(d) := ∂G_{s₀}(d)`（定义在 D_tr 上）。

需要一条前文的**引理 0**：`s₂ ≈ s₁⊕d ⟺ s₁ ≈ s₂⊕d⁻¹`（可逆型时）；以及 ⊖ 的既有性质：`s ⊖ s ≈ 1`。此外定理 D 的证明还显式用到 ⊖ 的一条初等性质，在此一并列出：

**引理 1（⊖ 保第一参数 ≈）**：`a ≈ a' ⟹ a⊖b ≈ a'⊖b`。

证明：由 ⊖ 定义 `a ≈ b ⊕ (a⊖b)`；由 a ≈ a′ 与 ≈ 的对称、传递性得 `a' ≈ b ⊕ (a⊖b)`；由 ⊖ 在基点 b 的唯一性（逐点忠实），`a'⊖b ≈ a⊖b`。∎

## 二、主定理

### 定理 A（最大可传输子幺半群）

对任意生成器 G（目标强可逆 + 逐点忠实）：

1. `1_X ∈ D_tr(G)`；
2. `d₁, d₂ ∈ D_tr(G) ⟹ d₁⊗d₂ ∈ D_tr(G)`，且 `T(d₁⊗d₂) ≈ T(d₁)⊗T(d₂)`；
3. G 在受限 actegory `(S_X, D_tr(G))` 上可传输，传输即 T；
4. **极大性**：若 `d ∉ D_tr(G)`，则不存在任何满足等变性的 T' 在 d 上有定义——D_tr 是差量空间中"G 能看见"的精确边界。

**证明**。

(1) `G(s⊕1) ≈ G(s)`（A1 + G 保 ≈），故 `G(s⊕1) ≈ G(s)⊕1_Y`；由 ⊖ 在基点 G(s) 的唯一性，`∂G_s(1) ≈ 1_Y`，与 s 无关。∎

(2) 固定任意 s。由 ⊖ 定义（取基点 `s⊕d₁`）与 A2（`s⊕(d₁⊗d₂) ≈ (s⊕d₁)⊕d₂`）及 G 保 ≈：

```text
G(s⊕(d₁⊗d₂)) ≈ G((s⊕d₁)⊕d₂) ≈ G(s⊕d₁) ⊕ ∂G_{s⊕d₁}(d₂)
```

`d₂ ∈ D_tr` ⟹ `∂G_{s⊕d₁}(d₂) ≈ T(d₂)`。又由 ⊖ 定义（基点 s）：`G(s⊕d₁) ≈ G(s) ⊕ ∂G_s(d₁) ≈ G(s) ⊕ T(d₁)`。代入并由 A2：

```text
G((s⊕d₁)⊕d₂) ≈ (G(s) ⊕ T(d₁)) ⊕ T(d₂) ≈ G(s) ⊕ (T(d₁)⊗T(d₂))
```

（第一步：`∂G_{s⊕d₁}(d₂)` 替换为 `T(d₂)` 用 A4 第二参数同余，`G(s⊕d₁) ≈ G(s)⊕T(d₁)` 两侧右加 `⊕T(d₂)` 用 A4 第一参数同余；第二步：A2，反向使用由 ≈ 的对称性保证。）

由 ⊖ 在基点 G(s) 的唯一性：`∂G_s(d₁⊗d₂) ≈ T(d₁)⊗T(d₂)`——右端与 s 无关，故 `d₁⊗d₂ ∈ D_tr`，且乘法性成立。∎

(3) 对 `d ∈ D_tr`：`G(s⊕d) ≈ G(s) ⊕ ∂G_s(d) ≈ G(s) ⊕ T(d)`（⊖ 定义 + 基点无关），即等变性；`T(1) ≈ 1` 由 (1)。∎

(4) 设 `d ∉ D_tr`，即存在 s, s' 使 `∂G_s(d) ≉ ∂G_{s'}(d)`。若 T' 是满足等变性的任意映射，则 `G(s⊕d) ≈ G(s) ⊕ T'(d)` 且 `G(s'⊕d) ≈ G(s') ⊕ T'(d)`；由 ⊖ 唯一性，`T'(d) ≈ ∂G_s(d)` 且 `T'(d) ≈ ∂G_{s'}(d)`——矛盾。∎

**注**：极大性不是平凡的同义反复——它说的是"可传输"与"基点无关"之间没有第三种状态：任何试图越过 D_tr 边界的传输必然在某一点违反等变性。这使 D_tr 成为**可检查的精确边界**。

### 定理 B（群情形）

若 D_X 与 D_Y 均可逆（group-like），则：

1. `d ∈ D_tr(G) ⟹ d⁻¹ ∈ D_tr(G)`，且 `T(d⁻¹) ≈ T(d)⁻¹`——`D_tr(G)` 是 D_X 的子群，T 是群同态。

**证明**。任取 s。由 A1、逆的定义、A4 第二参数同余与 A2：

```text
s ≈ s⊕1 ≈ s⊕(d⁻¹⊗d) ≈ (s⊕d⁻¹)⊕d
```

应用 G（保 ≈）并在基点 `s⊕d⁻¹` 用 ⊖ 定义：

```text
G(s) ≈ G((s⊕d⁻¹)⊕d) ≈ G(s⊕d⁻¹) ⊕ ∂G_{s⊕d⁻¹}(d) ≈ G(s⊕d⁻¹) ⊕ T(d)
```

由引理 0 的 `s₂ ≈ s₁⊕d ⟹ s₁ ≈ s₂⊕d⁻¹` 方向：

```text
G(s⊕d⁻¹) ≈ G(s) ⊕ T(d)⁻¹
```

由 ⊖ 唯一性：`∂G_s(d⁻¹) ≈ T(d)⁻¹`——与 s 无关，故 `d⁻¹ ∈ D_tr` 且 `T(d⁻¹) ≈ T(d)⁻¹`。∎

### 定理 C（核与商分解）

定义 G 的**核**：

```text
Ker(T) := { d ∈ D_tr(G) : T(d) ≈ 1_Y }
```

则：

1. `Ker(T) = { d : ∀s ∈ S_X, G(s⊕d) ≈ G(s) }`——G 完全不可见的差量；
2. `Ker(T)` 是 `D_tr(G)` 的子幺半群（群情形下是正规子群），是 T 诱导同余 `d~_T d' ⟺ T(d) ≈ T(d')` 的单位元等价类；
3. **第一同构**：`D_tr(G)/~_T ≅ Im(T)`，且 `Im(T) ≤ D_Y` 是子幺半群（前文定理 3）；
4. 差量世界三分：

```text
D_X = Ker(T) ⊔ (D_tr \ Ker(T)) ⊔ (D_X \ D_tr)
        ↑ 不可见     ↑ 忠实传输（商 ≅ Im(T)）   ↑ 基点敏感残差
```

**证明**。(1) `T(d) ≈ 1_Y ⟺ ∀s: G(s⊕d) ≈ G(s)⊕1_Y ≈ G(s)`（等变性 + ⊖ 唯一性 + A1）。(2) `Ker = [1_X]` 在 ~_T 下的等价类；子幺半群性由 T 是幺半群同态（定理 A(2)）给出；群情形下同态核正规。(3) ~_T 是同余：`d~d'`, `e~e'` ⟹ `T(d⊗e) ≈ T(d)⊗T(e) ≈ T(d')⊗T(e') ≈ T(d'⊗e')`（乘法性 + A4 的 ⊗ 两侧同余）；商映射 `T̄` 单、像为 Im(T)——第一同构定理的幺半群版本。(4) 三个集合按定义互斥且并满。∎

**解释（Koopman 对应）**：Ker(T) 是"本征值 1"的部分（G 对其完全不动）；`D_tr/~_T ≅ Im(T)` 是 G 忠实可见的谱结构（被传输且可区分）；`D_X \ D_tr` 是"非线性"残差（导数随基点漂移，对应 Koopman 中不在任何有限不变子空间内的可观测量）。

### 定理 D（管道判别）

设生成链 `G₁: A₀→A₁, G₂: A₁→A₂`（目标空间均强可逆 + 逐点忠实）。则

```text
d ∈ D_tr(G₁) 且 T_{G₁}(d) ∈ D_tr(G₂)  ⟹  d ∈ D_tr(G₂∘G₁)
```

且 `T_{G₂∘G₁}(d) ≈ T_{G₂}(T_{G₁}(d))`。即：**上游差量在整条链上的存活 = 逐级存活**。

**证明**。对任意 s：

```text
∂(G₂∘G₁)_s(d) = (G₂(G₁(s⊕d))) ⊖ G₂(G₁(s))
              ≈ (G₂(G₁(s) ⊕ T_{G₁}(d))) ⊖ G₂(G₁(s))       （G₁ 的等变性，G₂ 保 ≈，引理 1）
              = ∂(G₂)_{G₁(s)}(T_{G₁}(d))
              ≈ T_{G₂}(T_{G₁}(d))                            （T_{G₁}(d) ∈ D_tr(G₂)）
```

右端与 s 无关。∎

## 三、三个实例

### 3.1 ℤ mod 2：一个完全盲目的生成器

`S=D=ℤ`，`⊕=⊗=+`，`≈=相等`，`P(s) = s mod 2`。逐项计算：

- `∂P_s(d) = P(s+d) − P(s)`：d 偶 ⟹ `≡ 0`（与 s 无关）⟹ `d ∈ D_tr(P)`，`T(d) = 0`；d 奇 ⟹ 随 s 在 `{1,−1}` 交替 ⟹ `d ∉ D_tr(P)`。
- 故 `D_tr(P) = 2ℤ`，且 `T ≡ 0`，`Ker(T) = 2ℤ = D_tr(P)`，`Im(T) = {0}`。

这个例子说明极限情形：生成器可以"全盲"——所有它能传输的差量它全都看不见（定理 C 中前两类坍缩为一类）。任何奇差量（`d=1`：把结构整体平移一位）都被 mod 2 彻底搅碎，无法表述为对输出的差量。

### 3.2 子树提取器：三类差量的典型分布

设 X 是树空间，`G(s) :=` 提取路径 p 处的子树（生成器 = 投影到局部视图，对应"报表引擎只看 /entities 段"这类真实场景）。典型分类（示意性陈述：精确边界依赖所选 carrier 的合并语义与 p 的身份规则，此处给出的是标准 tree-delta 语义下的直觉分类）：

- **核内（死差量）**：只修改 p 子树之外的节点——`G(s⊕d) ≈ G(s)` 恒成立，`T(d) ≈ 1`。这些差量对下游完全不可见：若客户差量包中某条差量落在这里，它在生成链上是死重（白维护、白升级）。
- **D_tr 内（稳定差量）**：只修改 p 子树内部——`G(s⊕d) ≈ G(s) ⊕ d|p`，作用与基点无关。基线升级后只要 p 子树还在，差量照常成立。
- **D_tr 外（脆性差量）**：删除/重命名 p 的祖先节点、修改决定 p 是否存在的结构——导数随基点的祖先结构漂移。这类差量在基线升级时最容易断裂，应被工具链标记为迁移风险。

### 3.3 生成链 XORM → XMeta → XView：管道判别

对一条客户差量 Δ 判定其整链存活性：逐级检查 `Δ ∈ D_tr(G_orm)`，然后 `T_{G_orm}(Δ) ∈ D_tr(G_meta)`，再下一级。定理 D 保证逐级判定的合取**蕴涵**整链判定（充分条件）。注意反向不成立：下游若存在"常数型"生成器（把所有输入压成同一输出），整链存活而上游差量可能早已不可传输——因此逐级判定是**保守**判据，可能产生假警报，而非精确判定。这给 Delta VFS 升级场景一个可操作的迁移评估流程：**升级基线后，对每个客户差量逐级重算 T 并检验成员关系，即可静态定位会断裂的差量（保守上界），而不必整包重放**。

## 四、Koopman 对应（第二阶段）与强度边界

| Koopman | 本文 |
|---|---|
| 最大不变子空间（含给定可观测量） | `D_tr(G)`（最大可传输子幺半群/子群） |
| 本征值 1 谱（不动可观测量） | `Ker(T)`（G 不可见差量） |
| 商谱 / 不变子空间上的算子 | `D_tr/~_T ≅ Im(T)` 上的忠实传输 |
| 不在不变子空间内的可观测量 | `D_X \ D_tr`（基点敏感残差） |
| 逐段线性化 | 定理 D（管道逐级判别） |

**强度边界（如实声明）**：本定理链在数学上仍是初等幺半群/群作用代数——D_tr 的闭包证明约五行，群情形两行，难度低于 Darcs 的 hunk 换位正确性证明，也低于 lens 组合子良态性的归纳证明。它的非平凡性不在证明技巧，而在**可陈述性**：对任意生成器 G，不需要 G 满足任何预设条件，"G 能看见哪些差量"就是一个可检验、可分解、可在管道上复用的精确问题。Koopman 的不变子空间定理同样是初等线性代数——其价值在于把研究议程从"是否线性"推进到"哪里线性"。本文是同一动作在 GRC 中的完成。真正对应 Koopman 深层内容的（细化存在性定理——D_tr 外差量何时经空间细化变可传输；定量谱/收敛率——传输损失下界），仍是开放问题。

## 五、工程推论

1. **死差量检测**：对差量 d 检查 `∀s: G(s⊕d) ≈ G(s)`（或经验抽样：`T̂(d) ≈ 1`）——检测客户差量包中下游不可见的条目，支持清理与告警。
2. **升级迁移评估**：基线升级后逐级重算 T 与成员关系（定理 D），静态定位脆性差量（D_tr 外），替代整包重放测试。
3. **差量 hygiene 三分法**：核内 = 可删；D_tr 内 = 升级安全（可自动迁移）；D_tr 外 = 需人工复核的迁移风险。这给 Delta VFS 的客户定制治理一个可执行的分级标准。
