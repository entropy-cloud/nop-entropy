# 正负分离合并与双向伴随：分离定理与 doctrinal adjunction 阶梯

> 本文是 GRC 形式化系列第五篇。前文：[《差量传输理论》](../../ai-dev/analysis/2026-08/2026-08-26-grc-delta-transport-theory.md)、[《生成器看见了什么》](./grc-maximal-transportable-substructure.md)、[《差量之塔有多深》](./grc-delta-tower-classification.md)、[《沿 Koopman 路径的深层挖掘》](./grc-koopman-deep-stages.md)。本文回答两个问题：正负元素直接混合合并需要规范化吸收时，"分两部分分别结合、最后一步投影"的方案在范畴论中的对应与成立条件；以及双向设定 `F(A+dA) = B+dB`、`A+dA = G(B+dB)` 在补充假设下能推导出的结论。

## 引言

签名对 `(a, −b)` 的合并规则 `(a,−b)+(c,−d) = (a+c, −b−d)` 提出一个朴素但重要的方案：把差量的正部与负部**分开结合**，各自成链，最后一步再做投影。本文给出：(1) 该方案的范畴本质（Grothendieck 群化的未消元阶段）；(2) 它何时与直接混合合并等价——答案是**当且仅当没有"复活坐标"**（后到正部覆盖先到墓碑），定理 B 给出逐坐标的精确刻画；(3) 一般情形下正负互作用正是 proof-v2 十六规则所编码的 Zappa–Szép 式数据（直接混合合并需要规范化吸收——这正是 tagged 规则存在的理由）。

双向设定部分是 Kelly **doctrinal adjunction** 的实例：左伴随的传输（强幺半群结构）如何转移到右伴随、往返残差如何表达为单位差量、闭包如何给出不动差量子幺半群——五条相互关联的可证定理（C-G，部分嵌套、部分独立）。

## 一、正负分离合并

### 1.1 直积情形：分离免费

**定理 A（直积分裂）**：设差量幺半群分解为直积 `D ≅ D⁺ × D⁻`（φ 是幺半群同构），且作用满足 `s ⊕ (d⁺, d⁻) ≈ (s ⊕ d⁺) ⊕ d⁻`。则：

1. 任意混合链的合并分解为独立的正链与负链：`(⨂ᵢ dᵢ⁺, ⨂ᵢ dᵢ⁻)`；
2. 任意交错顺序在**单次链尾投影**后结果一致（正链、负链各自只需自身的结合性——纯覆盖半群自动满足）；
3. **推迟负部免费**：负部可以不付出任何共轭代价地全部挪到链尾。

**证明**：直积结合律使 (1) 逐分量成立；投影一致性由 proof-v2 推论 1（链尾统一投影）的分量版本给出；(3) 即分量交换律——直积中第二分量互不触碰。∎

### 1.2 坐标载体上的精确刻画：复活坐标

**坐标载体**（formal-proof 第四/五节的直觉核）：坐标集 C，差量 = 有限偏函数 `p : C ⇀ V ∪ {⊥}`（⊥ 为墓碑）。分解 `p = (p⁺, p⁻)`：p⁺ 取 V 值坐标，p⁻ 取 ⊥ 坐标（同一差量内互不相交）。合并（后到覆盖）：`r(c) = p₂(c)` 若定义，否则 `p₁(c)`，否则未定义。**分离合并**：正部先按覆盖合并、负部取并集、最后施加负部——`r'(c) = ⊥` 若 `c ∈ dom(p₁⁻) ∪ dom(p₂⁻)`，否则正部覆盖结果，否则未定义。

**定理 B（复活刻画）**：

```text
r = r'  ⟺  dom(p₂⁺) ∩ dom(p₁⁻) = ∅
```

即：分离合并与直接合并**等价当且仅当没有后到正部覆盖先到墓碑**（无复活）；差异恰为复活坐标集 `dom(p₂⁺) ∩ dom(p₁⁻)`。

**证明**（逐坐标 case analysis，六类互斥穷尽）：

| 坐标 c 的归属 | r(c) | r'(c) | 一致？ |
|---|---|---|---|
| c ∈ dom(p₂⁻) | ⊥ | ⊥（c ∈ 负部并集） | ✓ |
| c ∈ dom(p₂⁺) 且 c ∉ dom(p₁⁻) | p₂⁺(c) | p₂⁺(c) | ✓ |
| c ∈ dom(p₂⁺) 且 c ∈ dom(p₁⁻) | p₂⁺(c)（覆盖墓碑） | ⊥（墓碑遮蔽） | **✗ 复活坐标** |
| c ∉ dom(p₂) 且 c ∈ dom(p₁⁺) | p₁⁺(c) | p₁⁺(c)（c 不在任何负部） | ✓ |
| c ∈ dom(p₁⁻) 且 c ∉ dom(p₂) | ⊥ | ⊥ | ✓ |
| 其余 | 未定义 | 未定义 | ✓ |

前三类为 p₂ 有定义情形（p₂⁻ / p₂⁺且p₁⁻无 / p₂⁺且p₁⁻有）、后三类为 p₂ 未定义情形（p₁⁺ / p₁⁻ / 无），互斥且穷尽。唯一不一致类即复活坐标。∎

**树级对应**：复活在 tree-delta 载体的对应物正是 proof-v2 §6.3 规则 3——`Remove ⊗ Merge → Replace(Apply(empty_p, Merge))`：先删后建被规范化吸收为替换。即**复活坐标是 tagged 规范化的最小单元**。

### 1.3 范畴对应（搬运，如实标注）

1. **Grothendieck 群化**：签名对 `(a, −b)` 是群化 K₀ 的**未消元代表元**（M×M 的元素），合并规则是群化在消元前的合成；"最后一步投影"对应**消元商映射**（关系对的 coequalizer）。**tombstone 潜在空间就是未消元的群化中间态**；可逆型空间中消元由逆给出（a−b = a⊗b⁻¹），tree-delta 中消元不可逆、证据必须保留到投影前——这正是 S-N-V 阶段分离的范畴理由。
2. **Zappa–Szép 双交叉积**：一般情形正负不能自由互穿，互作用律是两类：墓碑遮蔽先到正部、正部覆盖先到墓碑。坐标载体上这就是定理 B 的两个 case；树级上就是 proof-v2 的 16 条 tagged 规则。**对照陈述（非本文定理）**：若 tree-delta 的差量可唯一分解为正部⊗负部，则其组合律构成 D⁺ 与 D⁻ 的 Zappa–Szép 乘积，16 规则即互作用数据——完整形式化列为开放问题。
3. **换位律**：分离重排的合法性是 2-结构的 interchange law。塔分类定理（2-group/Peiffer 恒等）保证可逆型空间的重排最多付出一层共轭（`Δᵢ₊₁⁻¹εΔᵢ₊₁`）；直积（定理 A）是共轭恒平凡的特例——**分离免费 ⟺ 负部与正部互作用平凡 ⟺ 差量幺半群直积化**（末一个 ⟺ 在正负部生成 D 且交平凡的条件下成立；交换性只是直积分解的必要条件）。

## 二、双向伴随阶梯

设定：生成器 F, G，F 可传输（传输 T_F）。记 G∘F 的残差为单位 η_A := (G∘F)(A) ⊖ A（强可逆 + 忠实时良定义）。以下定理构成**假设相互关联的阶梯**：部分嵌套（η≈1 是 F⊣G 的特例、双向 ≈id 强于单向 G∘F≈id）、部分独立（幂等假设与传输互逆假设不可比较）。

**定理 C（右逆传输 / doctrinal adjunction 的传输转移）**：若 `G∘F ≈ id_X` **且 F 本质满**（`∀y ∈ S_Y ∃A: F(A) ≈ y`），则 **G 在 Im(T_F) 上自动可传输**：

```text
T_G(T_F(d)) ≈ d   （mod Ker(T_F)）
```

若 T_F 单射（≈ 意义下，无核），`T_G|_{Im(T_F)} ≈ T_F⁻¹` 且是幺半群同态。

**证明**：对任意基点 y ∈ S_Y 取 A 使 `F(A) ≈ y`：

```text
G(y ⊕ T_F(d)) ≈ G(F(A) ⊕ T_F(d))      （A4 + G 保 ≈）
              ≈ G(F(A⊕d))               （F 的等变性）
              ≈ A⊕d ≈ G(y) ⊕ d          （G∘F≈id；G(y) ≈ A）
```

故 `∂G_y(T_F(d)) ≈ d` 与基点 y 无关；代表元选择经 Ker(T_F) 模糊；乘法性由 T_F 同态给出。T_G(1) ≈ 1。∎

**诚实标注（假设为何必要）**：`G∘F ≈ id` 只约束 G 在 Im(F) 上的行为；F 非本质满时存在基点 `y ∉ Im(F)` 使导数漂移（反例：S_X = {a,b}、S_Y = {y₀,y₁,y₂}、F 为截面、G 把 y₂ 坍缩到 a、T_F 为对换——在基点 y₂ 上 `∂G(σ₀₁) ≈ 1` 而在基点 y₀ 上 ≈ s）。**F 本质满**（或等价地把结论限制到子 actegory `(Im(F), Im(T_F))`）是该定理的必需假设。

**范畴识别（精确标注）**：这是 Kelly **doctrinal adjunction**（1974）的**单位恒等特例**：G∘F≈id 且 F 本质满时右伴随在左伴随的像上获得**强**传输；Kelly 的一般结论（左伴随强幺半群 ⟹ 右伴随 oplax 幺半群）不要求单位恒等，本文结论的强度来自 `G∘F≈id_X` 与 F 本质满这两个额外假设（且证明未使用伴随自然性，只用左逆性与满性）。

**定理 D（传输互逆 ⟹ 共轭残差族）**：若 `T_G ∘ T_F ≈ id_{D_X}`（且 G 在 Im(T_F) 上可传输），则 `G∘F` 有**恒等传输**（`(G∘F)(A⊕d) ≈ (G∘F)(A) ⊕ d`），且残差 κ_A := (G∘F)(A) ⊖ A 构成**共轭族**（群情形）：

```text
κ_{A⊕d} ≈ d⁻¹ ⊗ κ_A ⊗ d
```

**证明**：恒等传输由定理 C 的证明链直接给出（∂(G∘F)_A(d) ≈ T_G(T_F(d)) ≈ d）。共轭：`(G∘F)(A⊕d) ≈ (G∘F)(A) ⊕ d ≈ A ⊕ κ_A ⊕ d ≈ (A⊕d) ⊕ (d⁻¹⊗κ_A⊗d)`；与 κ_{A⊕d} 的定义比较，由 ⊖ 唯一性得证。∎

**注意（诚实）**：κ_A 未必全局不可见——除非 G∘F 幂等（见定理 F），此时 κ 为往返不动残差。

**定理 E（伴随传输恒等式）**：F ⊣ G（以 η 为单位，差量意义下），F、G 均传输，空间群式 + 强可逆 + 忠实。则：

```text
η_{A+dA} ≈ dA⁻¹ ⊗ η_A ⊗ T_G(T_F(dA))
```

**证明**：`(G∘F)(A+dA)` 两种算法：(1) 经传输：`G(F(A)+T_F(dA)) ≈ (G∘F)(A) ⊕ T_G(T_F(dA)) ≈ A ⊕ η_A ⊕ T_G(T_F(dA))`；(2) 按定义：`(A+dA) ⊕ η_{A+dA}`。两者相等，逐点忠实消去 `A⊕` 后左乘 `dA⁻¹` 得结论。∎

**注（假设诚实）**：本定理不依赖 F⊣G 的伴随结构——证明只用 η 的良定义与 F、G 的等变性；η 满足的恒等式**正是伴随单位自然性方块的差量形式**（`dA ⊗ η_{A+dA} ≈ η_A ⊗ T_G(T_F(dA))`），在此语境下自然性是定理的结论而非假设。

**推论**：(i) 若单位平凡（`η_A ≈ 1`，即结构往返为恒等），则 `T_G(T_F(dA)) ≈ dA`——传输互逆（与定理 C 一致）；(ii) 一般常值 η 只给出**换位关系** `dA ⊗ η_A ≈ η_A ⊗ T_G(T_F(dA))`——仅当 η_A 中心化（与一切差量可交换）时才退化为互逆。往返误差 = 单位差量：这是对称 lens 理论"amendment"的 GRC 版本。

**定理 F（闭包不动差量）**：若 `(G∘F)² ≈ G∘F` 且可传输（T := T_G∘T_F），则：

1. T 是**幂等差量闭包**：`T(T(d)) ≈ T(d)`；
2. `Fix(T) := { d : T(d) ≈ d }` 是含 1 的子幺半群；
3. 在 Fix(T) 上传输互逆——**不动差量（来回不变）= 闭包不动点**。（注：此处"不动差量"与第二篇的"稳定差量"（D_tr 内、下游效果与基线无关）是不同的概念，Fix(T) 与 D_tr 的关系见开放问题 2。）

**证明**：(1) 幂等性：由 `(G∘F)(A⊕d) ≈ (G∘F)(A) ⊕ T(d)` 两端再作用 G∘F，两次用结构幂等与等变性得 `(G∘F)(A⊕d) ≈ (G∘F)((G∘F)(A⊕d)) ≈ (G∘F)((G∘F)(A) ⊕ T(d)) ≈ (G∘F)(A) ⊕ T(T(d))`；与第一式比较，由逐点忠实得 `T(T(d)) ≈ T(d)`。(2) `T(1)≈1`；`T(d₁⊗d₂) ≈ T(d₁)⊗T(d₂) ≈ d₁⊗d₂`（乘法性）。(3) Fix 上 T = id。∎

**定理 G（强等价，阶梯顶点）**：`F∘G ≈ id ∧ G∘F ≈ id` ⟹ delta-conservative（《差量传输理论》引理 3）：T_F、T_G 互逆、ΔAct 同构。

**证明**：双向 ≈id ⟹ F 本质满（`y ≈ F(G(y))`），故定理 C 全效：T_G 在 Im(T_F) 上可传输且 `T_G∘T_F ≈ id`。T_F 本质满：对任意 e ∈ D_Y 与任意 B，`B⊕e ≈ F(G(B⊕e)) ≈ F(G(B) ⊕ T_G(e)) ≈ B ⊕ T_F(T_G(e))`（F∘G≈id + G 的等变性 + F 的等变性），由逐点忠实得 `e ≈ T_F(T_G(e))`，故 T_F 满。T_F 单：`T_F(d) ≈ T_F(d') ⟹ d ≈ d'`（等变性代入 + 忠实）。故 T_F 双射、T_G = T_F⁻¹（≈ 意义下）；引理 3 承担 ΔAct 同构封口。∎

**阶梯总表**：

| 假设 | 结论 | 范畴名 |
|---|---|---|
| G∘F ≈ id 且 F 本质满 | T_G 在 Im(T_F) 上自动存在（= T_F⁻¹ mod Ker） | doctrinal adjunction（传输转移） |
| T_G∘T_F ≈ id | G∘F 恒等传输 + 共轭残差族 | 差量层等价 |
| F ⊣ G（单位 η） | η_{A+dA} ≈ dA⁻¹η_A T_G(T_F(dA)) | 伴随传输恒等式 |
| η ≈ 1（单位平凡） | T_G∘T_F ≈ id（传输互逆） | 往返误差消失 |
| (G∘F)² ≈ G∘F | T 幂等；Fix(T) 子幺半群；其上互逆 | 闭包算子/Eilenberg–Moore 代数的差量版 |
| F∘G ≈ id ∧ G∘F ≈ id | delta-conservative | ΔAct 同构 |

## 结论

正负分离合并的范畴本质是 Grothendieck 群化的未消元阶段；其与直接合并的等价性由**复活坐标**（后到正覆盖先到墓碑）精确刻画——这正是 tagged 规范化的最小单元。双向设定是 Kelly doctrinal adjunction 的差量实例，五条结论构成相互关联的假设阶梯：从右逆自动传输，经伴随传输恒等式与共轭残差族，到闭包不动差量与强等价。两线交汇于一个事实：**差量的正负交互与差量的双向往返，最终都由同一组代数机制（覆盖、墓碑、共轭）控制**。
