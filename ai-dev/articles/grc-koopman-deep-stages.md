# 沿 Koopman 路径的深层挖掘：望远镜引理、导数函子与信息论谱

## 引言：Koopman 路径的完整地图

Koopman 研究路径的成熟阶段依次是：**(1)** 定义性观察（K = g∘φ 线性，1931）；**(2)** 谱理论（本征函数、不变子空间、遍历论谱分解）；**(3)** 函子与提升（因子映射的函子性、Carleman 线性化——无穷维提升总存在）；**(4)** 数据驱动（DMD/EDMD：有限字典近似 + 收敛与误差定理）；**(5)** 验证（ResDMD：计算谱的可认证性）。

GRC 系列前文已完成阶段 (1)（传输理论）与 (2) 的入门（D_tr 最大可传输子结构）。本文承担 (2) 的深入、（3）的全部与 (4) 的主体：

- **§一 群作用谱**：差量空间的齐性分解——结构空间是差量群的齐性商（orbit-stabilizer 的 GRC 实例）；
- **§二 望远镜与导数函子**：本文最深处。两个新定理——望远镜引理（差量的链式法则，无需逆）与导数函子定理（∂G 总构成作用群胚之间的函子；传输性 = 函子常值性）——把 Carleman 的"无穷维提升总存在"与 EDMD 的"有限逼近是内容"精确对接到 GRC；
- **§三 信息论谱**：传输的信息守恒与损耗（DPI 链、条件熵守恒判定、KS 熵率因子定理的导入、传输性检验的误判率公式——DMD 残差的概率版）；
- **§四 诚实台账**：搬运与识别的逐条标注；开放问题。

## 一、群作用谱

### 1.1 ΔAct 的识别

**命题 1（范畴识别）**：前文定义的范畴 ΔAct（对象 = 差量 actegory，态射 = 可传输生成器对 (G, T)）**就是**幺半群作用范畴（actegory 范畴）——对象 `(S, D, ⊕)` 中 D 是幺半群作用于 S，态射 `(f, T)` 满足 f 等变。识别是定义性的；其价值在于：**actegory 理论的全部结构结果可以整体导入**——本节的齐性空间定理、轨道-稳定子、以及下节的群胚函子构造，都是这个识别的直接后果。

### 1.2 齐性空间定理

**引理 A（忠实与稳定子）**：逐点忠实 ⟹ `Stab(s₀) = { d : s₀⊕d ≈ s₀ }` 平凡（= [1]）：`s₀⊕d ≈ s₀ ≈ s₀⊕1`，由逐点忠实得 `d ≈ 1`。反之，若只要求**全局忠实**（tree-delta 的情形），Stab(s₀) 可非平凡——只作用于其他基点、不改变 s₀ 的差量大量存在。

**定理 1（齐性空间）**：设 (S, D, ⊕, ⊗, ≈, 1) 强可逆 + 可逆型 + 全局忠实（≈ 为 D 上的全局作用商）。则作用传递（强可逆），且

```text
S ≅ Stab(s₀) \ D      （左陪集），    Stab(s₀) := { d : s₀ ⊕ d ≈ s₀ }
```

**证明**。Stab(s₀) 是子群：d₁,d₂ ∈ Stab ⟹ `s₀⊕(d₁⊗d₂) ≈ (s₀⊕d₁)⊕d₂ ≈ s₀⊕d₂ ≈ s₀`（A2 + A4 第一参数同余）；`s₀⊕d ≈ s₀ ⟹ s₀ ≈ s₀⊕d⁻¹`（引理 0）。良定义（左陪集判据）：`d₁⊗d₂⁻¹ ∈ Stab(s₀) ⟺ s₀⊕d₁ ≈ s₀⊕d₂`——(⟹) `s₀⊕d₁ ≈ s₀⊕((d₁⊗d₂⁻¹)⊗d₂)`（A3 + 逆 + A1 + A4 第二参数同余）`≈ (s₀⊕(d₁⊗d₂⁻¹))⊕d₂ ≈ s₀⊕d₂`（A2 + Stab + A4）；(⟸) `(s₀⊕d₁)⊕d₂⁻¹ ≈ (s₀⊕d₂)⊕d₂⁻¹ ≈ s₀⊕1 ≈ s₀`（A4 + A2 + 逆 + A1），即 `d₁⊗d₂⁻¹ ∈ Stab`。映射 `[d] ↦ s₀⊕d`：良定义如上；满射由强可逆；单射由上述 ⟺ 的 (⟹) 反向。∎

**推论 1.1（两种情形）**：(i) **逐点忠实**（引理 A）⟹ Stab 平凡，`S ≅ D`——齐性商退化为 ⊖ 双射，无谱内容（如实标注：此情形下定理 1 是 orbit-stabilizer 的平凡实例）；(ii) **全局忠实 + 可逆型但非逐点忠实**（忠实而非自由的群作用，如 S₃ 作用于三元素集：全局忠实 ✓、可逆型 ✓、逐点忠实 ✗，`Stab(1) = {e, (23)}` 非平凡）⟹ `Stab(s₀)` 非平凡，`S ≅ Stab(s₀)\D` 有真商内容——"只对基点 s₀ 不可见的差量"构成真稳定子。**注意（诚实标注）**：GRC 的动机实例 tree-delta 虽仅全局忠实，但**缺可逆型**（tombstone 无逆，见前文 §1.2/§10 分类学），定理 1 的陪集形式不适用于它——对它只有平凡分解 `S ≅ D/~₀`（orbit 映射的核等价，任意满射皆有，无谱内容）；此时 Stab(s₀) 仅构成子幺半群而非子群。**真商内容需要可逆型 + 非逐点忠实的群作用，而非单纯的"忠实性放宽"。**

**推论 1.2（总稳定子 = 恒等核）**：`∩_s Stab(s) = Ker(T_{id})`——与前文 D_tr 理论定理 C(1)（G=id 时不可见差量）逐字一致；在逐点忠实空间两者同为 [1]，在仅全局忠实空间（tree-delta）中 = {d : ∀s, Apply(s,d)=s}，与 proof-v2 的 ≈ 等价类 [1] 对应。

### 1.3 D_tr 的 oplax 函子性

**命题 2**：赋值 `G ↦ D_tr(G)` 随复合满足（前文定理 D）：

```text
D_tr(G₂∘G₁) ⊇ { d ∈ D_tr(G₁) : T_{G₁}(d) ∈ D_tr(G₂) }
```

即"最大可传输子结构"是 ΔAct 上的 oplax 子函子：复合结构的可传输部分包含逐级可传输部分的预像。**Koopman 对应**：不变子空间沿因子映射的提升（eigenfunction 的拉回）是函子性的——这里同样成立但方向为"下推"。

## 二、望远镜与导数函子

### 2.1 望远镜引理（差量的链式法则）

**定理 2（望远镜引理）**：设空间强可逆 + 逐点忠实（**不需要可逆型**）。对任意 a, b, c ∈ S：

```text
(a ⊖ b) ⊗ (c ⊖ a) ≈ (c ⊖ b)
```

**证明**。`b ⊕ ((a⊖b) ⊗ (c⊖a)) ≈ (b ⊕ (a⊖b)) ⊕ (c⊖a)`（A2）`≈ a ⊕ (c⊖a)`（⊖ 定义）`≈ c`（⊖ 定义）。又 `c ≈ b ⊕ (c⊖b)`（⊖ 定义）。由 ⊖ 在基点 b 的唯一性（逐点忠实），两者相等。∎

**意义**：这是差量的**链式法则**——从 b 到 a 的差量与从 a 到 c 的差量复合等于从 b 到 c 的差量。Change Actions 的逐点导数 `∂f(a, δa)` 满足的正是这条恒等式的逐点形式；本文证明它在 GRC 框架内**对任意结构三元组无条件成立**，且完全不依赖逆的存在。这是 §二全部内容的引擎。

### 2.2 导数函子定理

给定生成器 G : S_X → S_Y（目标强可逆 + 逐点忠实），构造**作用群胚** `S_X ⋊ D_X`：对象 = S_X，态射 = `(s, d) : s → s⊕d`，合成 `(s, d₁) ∘ (s⊕d₁, d₂) = (s, d₁⊗d₂)`（要求端点匹配）。**注**：合成、结合、恒等均在 ≈ 意义下成立（A2/A3/A1），严格说是"商对象上的弱群胚"；下文所有断言均在 ≈ 约定下陈述。定义导数对应：

```text
D(G)(s) := G(s)
D(G)(s, d) := (G(s), ∂G_s(d)) : G(s) → G(s) ⊕ ∂G_s(d) ≈ G(s⊕d)
```

**定理 3（导数函子）**：`D(G)` 是群胚同态——**对任意 G 都是函子**，无需任何传输性假设。

**证明**。对象部分显然。端点衔接：`G(s) ⊕ ∂G_s(d) ≈ G(s⊕d)`（⊖ 定义）。合成保持：设 `(s,d₁)` 与 `(s⊕d₁, d₂)` 可合成，则

```text
D(G)(s,d₁) ∘ D(G)(s⊕d₁,d₂) 的差量部分
= ∂G_s(d₁) ⊗ ∂G_{s⊕d₁}(d₂)
≈ G(s⊕d₁⊕d₂) ⊖ G(s)         （望远镜引理：a=G(s⊕d₁)、b=G(s)、c=G(s⊕d₁⊕d₂)）
= ∂G_s(d₁⊗d₂)                （桥接：G(s⊕(d₁⊗d₂)) ≈ G((s⊕d₁)⊕d₂) 由 A2 + G 保 ≈，
                              再由第二篇引理 1（⊖ 保第一参数）得 ∂G_s(d₁⊗d₂) ≈ G((s⊕d₁)⊕d₂) ⊖ G(s)）
= D(G)((s,d₁)∘(s⊕d₁,d₂)) 的差量部分
```

恒等保持：`∂G_s(1) ≈ 1`。∎

### 2.3 传输性 = 函子常值性

**定理 4（传输条件的群胚形式）**：G 可传输 ⟺ `D(G)` 在每个 d-纤维上常值：即对每个 d ∈ D_X，`∂G_s(d)` 与 s 无关；此时 `D_tr(G)` 恰是使函子常值的 d 的集合，且 `T = ∂G_{s₀}`。

**证明**：即定理 1（前文）的重述——基点无关性 ⟺ 纤维常值性。∎

**解释（Carleman/EDMD 对应，本文核心识别）**：

| Koopman 阶段 | GRC 对应 | 状态 |
|---|---|---|
| 无穷维函数空间的精确线性化（总存在） | 作用群胚上的导数函子 D(G)（总存在、总函子） | 本文定理 3 |
| Carleman 线性化（多项式系统 → 无穷维线性） | 任意生成器 → 群胚函子 | 本文 |
| 本征函数坐标（对角化/常值化） | d-纤维常值（传输性） | 本文定理 4 |
| EDMD 有限字典 + 收敛 | D_tr 的有限生成字典（**开放**） | §四 |

**细化存在性问题（前文 Open Problem 1）由此被重新表述**：注意作用群胚是**范畴层级的升高**（把"差量"重述为"带端点的态射"），不是 Open Problem 1 意义上的**同层细化** (S', D') → (S, D)——后者仍是开放问题。群胚语言给出的精确形式是：**是否存在有限生成/可有限描述的子差量空间，使 D(G) 在其上常值且覆盖 D_tr**——这是 EDMD 收敛定理（字典密度 ⟹ 逼近收敛）的 GRC 版本，本文不证（见 §四诚实台账）。

### 2.4 群胚层级上的 merge 与共轭（与塔分类的衔接）

作用群胚的语言统一前三篇的结果：塔分类定理（crossed module/2-group）是**差量群 D 的内结构**；本节导数函子是**沿 G 的外结构**；两者在群胚合成（望远镜恒等式）处交汇——前文 merge 公式 `d₁⁻¹⊗d₂`（差量塔分类篇定理 C）是望远镜恒等式的**中间因子**：`d₁ ⊗ (d₁⁻¹⊗d₂) ≈ d₂`，即 `(s⊕d₁)⊖s` 与 `(s⊕d₂)⊖(s⊕d₁)` 复合等于 `(s⊕d₂)⊖s`。GRC 的深层结构是**一个群胚**：对象 = 结构，态射 = 差量，合成 = ⊗，差异 = ⊖。

## 三、信息论谱

设变化过程为 D_X 上的概率分布 μ（客户定制差量的实际分布），传输 T : D_X → D_Y（本节假设 G 全传输，即 D_tr = D_X；非全情形逐段适用）。记 `ν := T_*μ`。

### 3.1 DPI 链定理

**定理 5（信息沿生成链单调不增）**：对生成链 G₁, G₂（传输 T₁, T₂），`d → T₁(d) → T₂(T₁(d))` 构成 Markov 链，由数据处理不等式（DPI）：

```text
I(d ; T₂∘T₁(d)) ≤ I(d ; T₁(d)) ≤ H(d)
```

即上游差量所含信息**沿生成链逐级递减**；任何下游都无法恢复被中间生成器压掉的信息。推论：x-diff 从下游提取上游差量的信息上限 = `I(d; T(d))`——**逆向提取的定量上界**。

### 3.2 守恒判定

**定理 6（守恒判定，注意方向；前提：d 离散且 H(d) < ∞）**：

```text
T 本质单射（a.e.） ⟺ H(d | T(d)) = 0 ⟺ I(d; T(d)) = H(d)
```

且 **delta-conservative（T 双射 a.e.）⟹ H(d|T(d)) = 0**。

**证明**：`H(d|T(d)) = 0 ⟺ d 是 T(d) 的 a.e. 函数 ⟺ T 本质单射`；T 双射 a.e. ⟹ 单射 a.e.。∎

**注意（反向不成立，诚实标注）**：单射不蕴含满射——反例 `T: ℤ→ℤ, T(d)=2d`：本质单射、条件熵为零，但非 delta-conservative（像缺奇数）。因此"零条件熵 ⟺ delta-conservative"为假，本文只断言单向。工程含义：**信息论守恒是升级迁移安全的必要条件判据而非充分判据**——对生成链逐级测量 `H(d|T(d))`，非零即必存在不可逆压平；为零仍需检查满性。

### 3.3 KS 熵率（导入，单向诚实）

把 μ 提升为 D_X^ℤ 上的平稳过程（差量历史），T 逐坐标作用为因子映射。由标准结果（Sinai 因子熵不等式 + Rokhlin 公式）：

```text
h(ν^ℤ) ≤ h(μ^ℤ)          （因子不增熵）
```

且 **delta-conservative（双射 a.e. ⟹ 本质单射因子）⟹ 熵率保持**。**注意（诚实标注）**：逆向不成立——Rokhlin 公式表明有限到一（finite-to-one）因子同样保熵，因此"熵率保持 ⟹ delta-conservative"为假。这是本文与 Koopman 谱理论最深的一个不对称：**信息守恒比结构守恒更便宜**。

### 3.4 传输性检验的误判率（DMD 残差的概率版）

设基分布 μ_S 于 S_X。对候选 d 做 m 次独立抽样 s₁,…,sₘ，若 `∂G_{sᵢ}(d)` 全同则输出"d 可传输，T(d) = 该值"。对不可传输的 d（值集合 V_d，每个值 v 的基质量 `μ_S(S_v)`）：

**定理 7（检验误判率）**：

```text
P(误判) = Σ_{v ∈ V_d} μ_S(S_v)^m   ~   max_v μ_S(S_v)^m   （m → ∞，渐近等价）
```

**证明**：m 个样本全部落在同一 S_v 的概率 = `Σ_v μ_S(S_v)^m`（事件互斥 + i.i.d.）。渐近：比值 `Σ_v p_v^m / p_max^m → #{v : p_v = p_max}`（当 p_max 由唯一 v* 取得时比值 → 1；指数速率 `(1/m)·log Σ_v p_v^m → log p_max` 恒成立）。∎

**意义（注意本质/逐点之分）**：检验测到的是 **μ_S-本质常值性**，而 `D_tr` 的定义是**逐点常值性**。当 μ_S 全支撑（每个 s 有正质量）时二者重合，此时"误判极限为 1 ⟺ 本质常值 ⟺ d ∈ D_tr"成立；无全支撑假设时只断言单向 `d ∈ D_tr ⟹ 极限为 1`。这**呼应 ResDMD 的认证关切**（数据驱动的计算何时认证了真对象），但机制不同：ResDMD 给出**确定性严格界**（verified residuals），本文给出**概率误判率**——误判率由非传输部分的质量控制（宽松类比：DMD 的残差/伪谱对应物是 `{S_v}` 的基质量分布）。

## 结论

沿 Koopman 路径的四层挖掘，本文给出了 GRC 的两个引擎性新定理：**望远镜引理**（差量链式法则，无逆成立——全部深层结构的代数来源）与**导数函子定理**（任意生成器的导数都是作用群胚函子；传输性 = 常值性——Carleman 普遍性的 GRC 版本）。加上群作用谱（齐性空间）与信息论谱（DPI/守恒/误判率），GRC 的形式系统现在覆盖 Koopman 路径的 (1)(2)(3)(4) 阶段的主体；真正等价于 EDMD 收敛定理的"有限字典逼近"仍是精确陈述过的开放问题。
