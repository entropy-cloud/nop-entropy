# 差量空间的线性化：谱定理与主差量定理

> 本文是 GRC 形式化系列第六篇。前文：[《差量传输理论》](../../ai-dev/analysis/2026-08/2026-08-26-grc-delta-transport-theory.md)、[《生成器看见了什么》](./grc-maximal-transportable-substructure.md)、[《差量之塔有多深》](./grc-delta-tower-classification.md)、[《沿 Koopman 路径的深层挖掘》](./grc-koopman-deep-stages.md)、[《正负分离合并与双向伴随》](./grc-split-merge-and-bidirectional-ladder.md)。本文完成 Koopman 谱理论阶段（Mezić 谱分解、DMD 主模态）的 GRC 对应：**把差量空间线性化**，使传输成为线性算子，从而引入 Perron–Frobenius 与 Gelfand 谱定理。

## 引言

Koopman 谱理论的全部内容（本征函数、谱分解、DMD 主模态）都建立在一个前提上：**可观测量构成线性空间**。GRC 的差量空间是幺半群——只有 ⊗ 乘法，没有加法与标量乘。这是前文一直回避线性谱内容的原因。本文做关键一步，也是第五篇 Grothendieck 群化对应的自然延续：

```text
V(D) := K(D) ⊗_ℤ ℝ        （差量向量空间）
```

其中 `K(D)` 是差量幺半群的 Grothendieck 群化（形式差 `[d₁]−[d₂]`），`⊗_ℤ ℝ` 是实系数基变换。于是：

- 传输 T（幺半群同态）诱导**线性算子** `T̄ : V(D_X) → V(D_Y)`；
- 有限字典的"传输封闭"条件给出**非负矩阵**；
- Perron–Frobenius 定理给出**主差量**（dominant delta）与**定制放大率** ρ——这就是 DMD 主模态的 GRC 对应物；
- Gelfand 公式把 ρ 解释为沿生成链的差量多集指数增长率。

**代价（如实声明）**：线性化是交换化——K(D) 只保留差量的**多集计数**结构，非交换信息（共轭、顺序、2-group 塔结构）在 V(D) 中坍缩。这恰是 Koopman 线性化的对偶代价：线性化丢掉非线性结构，换来的谱定理能刻画的部分正是 DMD 能刻画的部分。

## 一、线性化构造

### 1.1 差量向量空间

设 (D, ⊗, ≈, 1) 为差量幺半群（≈ 为同余）。`K(D)`：由 `[d]`（d ∈ D/≈）生成的自由阿贝尔群，模关系 `[d₁⊗d₂] = [d₁] + [d₂]` 与 `[1] = 0`。`V(D) := K(D) ⊗_ℤ ℝ`——有限实系数形式组合 `Σ αᵢ[dᵢ]`。

**正锥**：`V⁺(D) := { Σ αᵢ[dᵢ] : αᵢ ≥ 0 }`。

### 1.2 传输的线性化

对可传输生成器的传输 `T : D_X → D_Y`（第一篇引理 2：幺半群同态），定义

```text
T̄(Σ αᵢ[dᵢ]) := Σ αᵢ[T(dᵢ)]
```

**良定义**：`[d₁⊗d₂]` 映到 `[T(d₁⊗d₂)] ≈ [T(d₁)⊗T(d₂)] = [T(d₁)]+[T(d₂)]` ✓；`[1] ↦ [1] = 0` ✓。

**定理 1（线性化函子）**：

1. `(G, T) ↦ T̄` 是从 ΔAct 到实向量空间范畴 Vec 的**函子**：`T̄_{G₂∘G₁} = T̄_{G₂} ∘ T̄_{G₁}`，恒等映恒等；
2. **正性自动**：`T̄(V⁺(D_X)) ⊆ V⁺(D_Y)`（T 把差量映为差量，锥由 `[d]` 生成）；
3. **线性化边界 = D_tr**：只有可传输差量进入 V(D) 的像——不可传输生成器没有 T，因而没有 T̄；可传输但不可见的差量（Ker(T)）映为 0 向量：`Ker(T̄) ⊇ V(Ker(T))`。

**证明**。(1) `T̄₂(T̄₁([d])) = T̄₂([T₁(d)]) = [T₂(T₁(d))]`，与传输复合定理（第一篇定理 2）一致。(2) 逐字。(3) `d ∈ Ker(T)` ⟺ `T(d) ≈ 1` ⟹ `T̄([d]) = [1] = 0`。∎

**解释（与核商分解的一致性）**：第二篇的核商分解 `D_tr/~_T ≅ Im(T)` 在谱层面有对应。**恒真的版本**（秩-零化/第一同构）：`V(D_tr)/Ker(T̄) ≅ V(Im(T))`，且 `V(Ker(T)) ⊆ Ker(T̄)`（定理 1(3)）。注意**幺半群一般情形** `V(D_tr)/V(Ker(T)) ≇ V(Im(T))`——反例：`D_tr = ℕ²`（⊗=+）、`T(a,b) = a+b`，则 `V(D_tr)/V(Ker(T)) = ℝ² ≇ ℝ = V(Im(T))`；原因是 ~_T 的同余 `[x]−[y]`（x~_T y）一般不能由核生成元线性生成。**群情形（可逆型）下等号成立**（x~_T y ⟺ x⊗y⁻¹ ∈ Ker ⟹ `[x]−[y] = [x⊗y⁻¹]`）。线性化保持"谱可见部分"的商结构，但核的线性生成在非群情形有泄漏。

## 二、主差量定理

### 2.1 字典与传输封闭

取**字典**：有限集 `{d₁, …, dₙ} ⊆ D_tr(G)`，且**传输封闭**：存在非负整数矩阵 `M = (aᵢⱼ)` 使

```text
T(dⱼ) ≈ d₁^{⊗a_{1j}} ⊗ d₂^{⊗a_{2j}} ⊗ … ⊗ dₙ^{⊗a_{nj}}        （j = 1..n）
```

即每个字典差量的传输仍是字典内差量的积。则 `W := span{[d₁],…,[dₙ]} ⊆ V(D_X)` 是 `T̄`-不变子空间，且 `T̄([dⱼ]) = Σᵢ aᵢⱼ[dᵢ]`——本征方程机制 `T̄(Σxⱼ[dⱼ]) = Σᵢ(Mx)ᵢ[dᵢ]` 不依赖 `[dᵢ]` 线性无关（与 EDMD 字典同理）；"矩阵表示"一词仅在生成元无关时取字面意义。重数 `aᵢⱼ` 按归纳所选定的规范展开计（词典间存在 ≈ 关系时展开不唯一，但结论只依赖存在性）。M ≥ 0。

**注意**：这个条件有明确的工程含义——**传输封闭的字典 = 生成链上"闭包的自定制语言"**：客户定制差量在每级生成后仍是可表达的定制差量（不逃逸出定制词汇表）。

### 2.2 主差量定理（Perron–Frobenius 的 GRC 版）

**定理 2（主差量）**：设字典传输封闭，M 为其非负矩阵，`ρ := ρ(M)` 为谱半径。则：

1. **（弱 PF）** `ρ ≥ 0` 是 M 的本征值，存在 `x ≥ 0, x ≠ 0` 使 `Mx = ρx`；于是存在**主差量** `d* := Σᵢ xᵢ[dᵢ] ∈ V⁺(W) \ {0}`，满足

```text
T̄(d*) = ρ · d*
```

2. **（不可约 ⟹ 唯一正）** 若 M 不可约，x 可取得严格正且唯一（精确到标量）；不可约的 GRC 含义：**字典模式互相可达**——每个字典差量经有限步传输都包含其他每个字典差量（作为因子）。
3. **（本原 ⟹ 收敛到主分量）** 若 M 本原（某次幂 M^k > 0，即 k 步后每个字典差量同时含全部字典差量为因子），则对任意 `v ∈ V⁺(W)`：

```text
lim_{m→∞}  T̄^m(v) / ρ^m  =  c · d*      （c ≥ 0 为常数）
```

**证明**：全部为 Perron–Frobenius 定理的标准结论（Perron 1907 / Frobenius 1912；本原情形的极限公式见 Perron 极限定理），本文的贡献在于**条件与对象的识别**：字典传输封闭 ⟹ 非负矩阵；主差量 d* 是正锥中的本征向量。**非零性通有假设**：若词典存在非负线性依赖（如含 d ≈ 1，或 `dᵢ⊗dⱼ ≈ 1` 使 `[dᵢ]+[dⱼ]=0`），Σxᵢ[dᵢ] 可能为零向量——通有情形（约化词典，[dᵢ] 无非负依赖）下 d* ≠ 0；下文默认约化词典。∎

**GRC 含义（DMD 主模态对应）**：`d*` 是生成链的**主定制模式**——在传输下只被缩放不被混杂的模式；`ρ` 是**定制放大率**。注意 `d*` 是字典差量的非负线性组合（模式），未必是单个差量；当 x 为 0/1 向量时退化为单个字典差量。三个区间：

```text
ρ > 1 ：该定制模式沿生成链逐级放大（下游复制更多）
ρ = 1 ：守恒（逐级等量传递）
ρ < 1 ：衰减（下游逐步压平）
```

这正是 DMD 主模态（dominant Koopman mode）的对应物：DMD 从轨迹数据提取的支配模态 = 本文从传输矩阵提取的主差量；ρ = 支配模态的增长率。

### 2.3 谱半径 = 增长率（Gelfand）

**定理 3（增长率）**：`(M^m)ᵢⱼ` = 传输 m 步后 `T^m(dⱼ)` 的字典展开中 `dᵢ` 的重数（由传输封闭归纳）；总重数 `‖M^m‖`（所有元素和）满足 Gelfand 公式

```text
lim_{m→∞} ‖M^m‖^{1/m} = ρ
```

**GRC 含义**：沿生成链第 m 级的**差量多集规模以 ρ^m 为渐近指数速率增长**（非本原时可有周期振荡或多项式因子，本原情形的逐点收敛见定理 2(3)）——定制放大率 ρ 的精确操作含义：它度量生成链上定制信息的多重复制速率。衔接轨道理论（第四篇望远镜引理）：主差量的字典重数增长正是沿主模式的"轨道导数"累积的线性化计数。

**证明**：Gelfand 公式（标准）；重数归纳由传输封闭定义直接给出。∎

### 2.4 特征差量分解（DMD 模态分解对应）

**推论**：M 本原时，任意字典组合 `v` 分解为

```text
T̄^m(v) = ρ^m · (c·d* + o(1))
```

长程行为由主分量支配、其余为**瞬态**——DMD 模态分解（dominant + transient modes）的结构对应。工程含义：**对生成链的传输矩阵做一次谱分析，即可预判每个定制模式的长期命运**——升级迁移评估从"逐包重放"变为"谱预判"。

## 三、诚实台账与边界

| 结果 | 性质 | 说明 |
|---|---|---|
| V(D) = K(D)⊗ℝ 线性化 | **搬运**（Grothendieck 群化 + 基变换） | 第五篇 §1.3 的构造的谱应用 |
| 定理 1（线性化函子/正性自动/边界=D_tr） | **本文自证**（逐字核对） | 正性自动与 Ker 一致性是识别性观察 |
| 定理 2（主差量） | **搬运 + 识别** | 证明是 PF 标准结论；"字典传输封闭 ⟹ 矩阵、d* = 主定制模式、ρ = 定制放大率"是识别 |
| 定理 3（增长率） | **搬运 + 识别** | Gelfand 标准；重数计数的 GRC 读法是识别 |
| 推论（模态分解） | **搬运 + 识别** | Perron 极限定理；DMD 对应是识别 |

**三条诚实的边界**：

1. **线性化丢非交换信息**：K(D) 是交换化——共轭、顺序、2-group 塔结构（第三篇）在 V(D) 中不可见。谱理论刻画的是差量的**交换影子**（多集计数）；正如 Koopman 线性化丢掉非线性结构、只保留不变子空间上可恢复的部分。**塔结构与谱理论是互补的两个视角，而非同一事物的两层**。
2. **有限性是真假设**：字典有限 + 传输封闭是强条件——它断言"定制语言在生成链上闭包"。不可约/本原刻画的是字典的连通性等级；现实字典可能可约（定制模式分成互不混合的族）——此时定理 2.1 的弱形式仍成立（ρ 与某非负本征向量存在），且各闭连通类各有自己的 ρᵢ。
3. **非平稳开放**：本定理是"自治"版本（单矩阵 M）；生成链若逐级改变传输（各层 M 不同），对应随机矩阵乘积/Oseledets 理论——列为开放问题。

## 四、工程推论

1. **定制放大率诊断**：对 XORM→XMeta→XView 链计算各级传输矩阵的谱半径 ρᵢ——预判每个定制族沿链的放大/衰减；ρ > 1 的族是升级迁移的高风险热点（下游定制多集爆炸）。
2. **主定制模式提取**：主差量 d* 是"最顽固"的定制模式——迁移评估优先检查它对基线升级的敏感度。
3. **字典设计准则**：选择传输封闭的定制词汇表，使谱分析可行；不可约性 ⟺ 词汇表内部互相可达（每个定制模式能被其他模式重构），是词汇表健康度指标。

## 开放问题

1. 非平稳链（逐级矩阵 Mᵢ 不同）的 Lyapunov 谱（Oseledets）——GRC 版的随机矩阵乘积理论。
2. 可约字典的分块谱（各闭连通类的独立放大率）。
3. 数值实验：对真实 Nop 生成链（ORM/Meta/View）实测传输矩阵与谱半径。

## 结论

差量空间线性化完成了 Koopman 谱理论阶段的 GRC 落地：传输成为线性算子，非负传输矩阵的 Perron–Frobenius 理论给出**主差量与定制放大率**——DMD 主模态的对应物；Gelfand 公式把放大率解释为沿生成链的差量多集指数增长率。这是系列第一次给出**谱内容**（本征对象与增长率），其代价——非交换结构坍缩为交换影子——与 Koopman 线性化的代价结构同型（丢非线性结构、只保留不变子空间上可恢复的部分）。至此，Koopman 路径从 (1) 定义性观察到 (4) 谱理论的全部阶段在 GRC 中都有了对应定理。
