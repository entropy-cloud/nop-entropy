## 摘要

前八篇的 GRC-Koopman 对应是**对象级**的：传输条件对应线性化判据，`D_tr` 对应最大不变子空间，望远镜引理对应链式法则，Perron–Frobenius 对应主模态。本文把对应推进到**算子级**，并由此得到三条新定理：

1. **GRC-Koopman 算子与谱不动点定理**：把每个源差量 `d` 映为“差量值可观测量” `K_G(d)(s)=∂G_s(d)`；`D_tr(G)` 恰好是全体基空间 Koopman 算子 `U_σ` 的联合不动点谱（特征值 1）。
2. **遍历平均传输定理**：对任意基分布 μ，`T_μ(d)=E_s[∂G_s(d)]` 是导数可观测量的常数投影；它满足均值等变性，是 L² 最优的“统计传输”。当基分布来自遍历的基线演化 F 时，Birkhoff 平均把**任何**差量 d 变成 μ-a.e. 的常值可观测量——即每个差量都有遍历平均意义下的传输；精确可传输当且仅当残差为零。
3. **有限域多项式生成器的精确字典定理**：对 `G:F_q^n→F_q^m`（约化多项式），单项式字典是**精确**有限字典：`d` 可传输当且仅当 `G(s+d)-G(s)` 作为 s 的多项式没有非零非常数项；此时 `T(d)=G(d)-G(0)`。因此 `D_tr(G)` 是有限多个多项式方程定义的代数集，传输性检验是**确定性零误差**的。这直接关闭了第四篇开放问题 1（EDMD 收敛）在多项式生成器类上的问题。

第 1、2 条是新识别 + 本文自证；第 3 条的证明用到有限域上约化多项式表示的唯一性（标准事实），但定理的 GRC 陈述、系数判据、代数簇结论与零误差验证算法是新的。第 3 条已经过全函数穷举验证（见 §5）。

## 0. 记法

沿用前文：`(S_X,D_X,⊕,⊗,≈,1)` 为差量 actegory；目标空间强可逆 + 逐点忠实，故 `⊖` 良定义；`∂G_s(d)=G(s⊕d)⊖G(s)`；`D_tr(G)={d:∂G_s(d) 与 s 无关}`。本文还使用第六篇的线性化 `V(D)`。当 `D` 可逆时，`V_G(d)(s,s')` 记可逆型残差。

## 1. GRC-Koopman 算子

**定义（差量值可观测量）**。对生成器 `G:S_X→S_Y`，定义

```text
O_X(D_Y) := S_X → D_Y            （逐点 ≈ 的差量值可观测量）
K_G : D_X → O_X(D_Y)
K_G(d)(s) := ∂G_s(d)
C(D_Y)  := { f ∈ O_X(D_Y) : ∃t∈D_Y, ∀s, f(s)≈t }   （常值可观测量）
```

对基空间自映射 `F:S_X→S_X`，定义基空间 Koopman 算子

```text
U_F : O_X(D_Y) → O_X(D_Y),   U_F(f)(s) := f(F(s))
```

对生成器链 `G1:S_X→S_Y`、`G2:S_Y→S_Z`，定义算子积

```text
(K_{G2} ⋆ K_{G1})(d)(s) := ∂G2_{G1(s)}( K_{G1}(d)(s) )
```

**定理 1（GRC-Koopman 函子性与传输的谱判据）**。

1. `K_{id}(d) ≈ d`；
2. `K_{G2∘G1}(d)(s) ≈ (K_{G2} ⋆ K_{G1})(d)(s)`；
3. `d ∈ D_tr(G) ⟺ K_G(d) ∈ C(D_Y)`，且此时 `T(d)` 就是该常值的代表元。

**证明**。(1) 当 `G=id:S_X→S_X` 且源目标为同一 actegory 时，由 `∂(id)_s(d)=d`。(2) 逐行：

```text
∂(G2∘G1)_s(d)
= G2(G1(s⊕d)) ⊖ G2(G1(s))                      （定义）
≈ G2(G1(s) ⊕ ∂G1_s(d)) ⊖ G2(G1(s))             （∂G1 定义 + G2 保 ≈）
= ∂G2_{G1(s)}(∂G1_s(d))                          （∂G2 定义）
= (K_{G2} ⋆ K_{G1})(d)(s)
```

中间一步正是第四篇望远镜引理。(3) 展开两个定义即得：基点无关 ⟺ 可观测量常值。∎

**注（与前文的关系）**。第四篇的导数函子 `D(G)` 是群胚态射；本文的 `K_G` 是同一个数据的**算子形式**：导数函子逐态射写，Koopman 算子逐差量写。定理 1(2) 是 Carleman 提升的函子性在 GRC 中的显式形态。

## 2. 谱不动点定理

**定义（残差可观测量）**。可逆型时定义

```text
V_G(d)(s,s') := K_G(d)(s) ⊗ K_G(d)(s')^{-1}
```

线性化后写加性形式

```text
δ_G(d)(s,s') := [K_G(d)(s)] − [K_G(d)(s')] ∈ V(D_Y)
```

**定理 2（D_tr 是联合不动点谱）**。设 `S_X` 至少有两个元素。

1. `d ∈ D_tr(G) ⟺ V_G(d)(s,s')≈1 (∀s,s')`；线性化后 `⟺ δ_G(d)≡0`。
2. `f ∈ O_X(V(D_Y))` 是常值函数，当且仅当 `f` 在所有基空间双射 `σ:S_X→S_X` 下不动，即 `U_σ f = f (∀σ)`。
3. 因此

```text
D_tr(G) = { d : U_σ K_G(d) = K_G(d),  ∀σ∈Sym(S_X) }
```

即 `D_tr(G)` 是整族基空间 Koopman 算子 `{U_σ}` 的**联合本征值 1 子空间**在差量空间的拉回。

**证明**。(1) 逐点忠实：`V=1` 当且仅当两点值 ≈ 相等。(2) 若 f 常值显然不动；反之，任取 `s≠s'`，取对换 σ 交换二者，由 `f(s)=f(σ(s'))=f(s')` 得任意两点值相等。(3) 由 (1)(2) 与定理 1(3)。∎

**GRC 含义**：`D_tr` 不是人为划出的“可传输子集”，而是**一族 Koopman 算子的公共谱子空间**。这与 Koopman 理论中“不变子空间 = 本征函数张成”的读法同构：基点漂移由对称群生成，传输性就是漂移不变性。

## 3. 遍历平均传输定理

设 `V(D_Y)` 为有限维赋范向量空间。μ 是 `S_X` 上的概率（本节先取有限支撑；一般测度版本见定理 4）。

**定义（统计传输）**。

```text
P_μ f := ∫_S f dμ           （把可观测量投影为常值可观测量）
T_μ(d) := ∫_S K_G(d) dμ = Σ_s μ(s) [∂G_s(d)] ∈ V(D_Y)
R_μ(d) := K_G(d) − T_μ(d)   （零均值残差）
```

`T_μ(d)` 称为 d 的 **μ-统计传输**：它是虚拟差量（线性组合），不要求落在 `D_Y` 内。

**定理 3（谱传输投影）**。

1. `P_μ` 是 `O_X(V(D_Y)) → C(V(D_Y))` 的线性幂等投影，`P_μ^2=P_μ`。
2. **均值等变性**：在结构与差量的联合线性化 `A(S_Y,D_Y)` 中，

```text
E_μ[G(s⊕d)] = E_μ[G(s)] + T_μ(d)
```

3. **精确情形**：若 `d∈D_tr(G)`，则 `T_μ(d)=[T(d)]`。反之，若 μ 全支撑且 `R_μ(d)=0` μ-a.e.，则 `d∈D_tr(G)`。
4. **L² 最优**：若 `V(D_Y)` 为 Hilbert 空间且 `K_G(d)` 平方可积，则 `T_μ(d)` 是变分问题

```text
min_{t∈V(D_Y)} E_μ ‖ K_G(d)(s) − t ‖²
```

的唯一解；残差与常值子空间正交。

**证明**。(1) 常数的平均值仍为自身。(2) 由 `G(s⊕d)≈G(s)⊕∂G_s(d)`，在联合线性化中 `[G(s⊕d)]=[G(s)]+[∂G_s(d)]`，对 μ 积分即得。(3) 正方向代入；反方向由全支撑逐点成立。(4) Hilbert 投影定理：`E‖f−t‖²` 的极小点是 `E f`。∎

**定理 4（遍历平均传输；GRC 的 Birkhoff 定理）**。设 `F:S_X→S_X` 是 μ-保测且遍历的基线演化，`K_G(d)` 为 Bochner 可积。则对 μ-a.e. s，

```text
lim_{n→∞} (1/n) Σ_{k=0}^{n-1} K_G(d)(F^k s) = T_μ(d)   （常值向量）
```

因此：**任意源差量 d 沿遍历基线 F 的时间平均都收敛到一个 μ-a.e. 常值虚拟传输 `T_μ(d)∈V(D_Y)`；它精确可传输当且仅当时间平均残差为 0**。

**证明**。收敛部分是向量值 Birkhoff 遍历定理：时间平均收敛到关于 F-不变 σ-代数的条件期望；F 遍历使不变 σ-代数平凡（μ-a.e.），极限为常数 `E_μ[K_G(d)]=T_μ(d)`。逐点识别与均值等变性由定理 3 给出。∎

**有限循环的初等版本（本文完整自证）**：若 `S_X` 是单循环 `s0→F(s0)→…→F^{N-1}(s0)`，μ 均匀，则对每个 s 有限平均

```text
T_F(d) = (1/N) Σ_{k=0}^{N-1} [∂G_{F^k(s)}(d)]
```

与 s 无关，且定理 3(2)(3) 逐字成立。证明：求和遍历整个循环，换元 `s'=F(s)` 不改变和。

**为什么这是新的**：此前系列只承认二值答案——`d∈D_tr` 或 `d∉D_tr`，并把后者全部归为“脆性残差”。定理 3/4 给出第三类对象：**统计传输 `T_μ(d)` 与零均值残差**。它是 Koopman 谱投影在 GRC 中的对应物，也是第四篇开放问题 2（非平稳变化过程）在“给定基分布”这一层的正向结果。

## 4. 有限域多项式生成器：精确有限字典

### 4.1 单项式字典

设 `q=p^r`，`F_q` 为 q 元有限域。取

```text
S_X = D_X = F_q^n,   ⊕ = ⊗ = 坐标加法
S_Y = D_Y = F_q^m
```

生成器 `G:F_q^n→F_q^m` 的每个坐标是函数 `F_q^n→F_q`。经典事实：每个这样的函数有唯一**约化多项式**表示

```text
G_j(x) = Σ_{α∈[0,q-1]^n} c_{jα} x^α,   x^α = ∏_i x_i^{α_i}
```

（因 `x_i^q=x_i`，每个变量次数只需 0..q−1；`q^n` 个单项式构成函数空间基。）

**定义（多项式导数）**。

```text
P_{G,d}(s) := G(s+d) − G(s) ∈ F_q^m
```

**定理 5（精确有限字典定理）**。设 G 为约化多项式生成器。

1. 对每个 d，`P_{G,d}` 属于有限字典 `W = span{x^α : α∈[0,q-1]^n}`。
2. `d∈D_tr(G)` 当且仅当对每个输出坐标 j 与每个非零指数 `β≠0`，

```text
C_{jβ}(d) := Σ_{α ≥ β} c_{jα} binom(α,β) d^{α−β} = 0     （在 F_q 中）
```

其中 `α≥β` 表示逐坐标，`binom(α,β)=∏ binom(α_i,β_i)`。
3. 此时传输精确为

```text
T(d) = G(d) − G(0)     （逐坐标）
```

4. `D_tr(G)` 是 `F_q^n` 中由 `{C_{jβ}}` 定义的代数集；传输性检验只检查 `m(q^n−1)` 个有限域方程，**零误差**。

**证明**。由二项展开

```text
P_{G,d,j}(s) = Σ_α c_{jα} [ (s+d)^α − s^α ]
             = Σ_α c_{jα} Σ_{0≤β≤α} binom(α,β) s^β d^{α−β} − Σ_α c_{jα} s^α
```

`s^0` 系数为 `Σ_α c_{jα} d^α − c_{j0} = G_j(d)−G_j(0)`；对 `β≠0`，系数恰为 `C_{jβ}(d)`。由约化表示唯一性，`P_{G,d,j}(s)` 为常值多项式当且仅当所有 `β≠0` 的系数为零。而 `d∈D_tr(G)` 正是 `∀s: ∂G_s(d)=∂G_0(d)=G(d)−G(0)`。∎

**推论 5.1（F₂ 的 ANF 判据）**。`q=2` 时 Lucas 定理给出 `binom(α,β)=1 (mod2) ⟺ β⊆α`（逐位）。故 d 可传输当且仅当 `s ↦ G(s⊕d)⊕G(s)` 的代数正规型（ANF）中**不含任何含 s 变量的单项式**；此时 `T(d)=G(d)⊕G(0)`。

**推论 5.2（ResDMD 型零残差证书）**。定义残差向量

```text
r(d) := ( C_{jβ}(d) )_{j,β≠0}
```

则 `d∈D_tr(G) ⟺ r(d)=0`。这是确定性证书：不像第七篇定理 7 的概率误判率，多项式类上**没有假阳性也没有假阴性**。Koopman 对应：单项式字典是 EDMD 的**精确**字典，有限维逼近误差恒为 0。

**例子（非平凡 D_tr）**。`q=2,n=3`，取

```text
G(x) = x0·x1 ⊕ x0·x2 ⊕ x1·x2
```

直接计算得 `D_tr(G)={000,111}`：全零差量传输为 0；全局翻转 `d=111` 的导数恒为 1（G 与 G∘翻转 处处互补），故 `T(111)=1`。系数判据给出同一结果。

**验证算法**（脚本实现）：

```text
1. 由 G 的函数表或表达式求约化系数 c_{jα}；
2. 对每个 d 计算 C_{jβ}(d)；
3. 全部为零则输出 Some(G(d)−G(0))，否则 None。
```

## 7. 沿 Koopman 路线的新开放问题

1. **非多项式生成器的有限字典**：对哪些生成器类，存在一个有限字典使残差向量 `r(d)` 的零集恰好等于 `D_tr(G)`？定理 5 说明有限域多项式类是第一个正例；求最大类。
2. **统计传输的实现化**：`T_μ(d)` 是虚拟差量；何时存在真实差量 `d̂∈D_Y` 使 `[d̂]=T_μ(d)`？给出 μ 的组合条件，并研究沿生成链的误差传播。
3. **谱间隙与收敛率**：定理 4 的 Birkhoff 平均收敛速率；`K_G(d)` 的自相关衰减对应 GRC 传输的谱间隙。
4. **D_tr 的代数簇结构**：对有限域多项式 G，研究 `D_tr(G)` 的维数、不可约分支与生成链上的拉回/前推。
5. **联合不动点谱的 2-范畴化**：定理 2 的对称群作用与第四篇开放问题 4 的 2-细胞结构合并，求 `D_tr` 的 2-谱分解。

## 结论

把 `∂G_s(d)` 看作**可观测量**，GRC 就拥有了自己的 Koopman 算子 `K_G`。这条线索同时给出三条新定理：`D_tr` 的联合不动点谱、任意差量的遍历平均传输、多项式生成器的精确有限字典。它们分别落在 Koopman 研究路径的谱阶段、遍历阶段与数据驱动阶段，并且把前八篇标为开放的两个问题（有限字典逼近、非平稳变化）推进到了第一批可证的正例。
