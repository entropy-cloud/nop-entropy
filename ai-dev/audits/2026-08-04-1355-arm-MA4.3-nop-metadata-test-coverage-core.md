## 发现清单

### [P2-MA4-301] processor 单元测试层空壳：核心 execute() 在单元层零保护

- **文件**: `nop-metadata/nop-metadata-service/src/test/java/io/nop/metadata/service/query/TestEntityEntityJoinAggregationProcessor.java:12-27`（同型：TestExternalExternalJoinAggregationProcessor:13-28、TestMixedSameDbJoinAggregationProcessor:12-27、TestCrossDbInMemoryAggregationProcessor:17-31、TestEntityAggregationProcessor:30-44、TestSqlAggregationProcessor:28-42）
- **证据片段**:
  ```java
  @Test public void testImplementsAggregationProcessor() {
      assertTrue(new EntityEntityJoinAggregationProcessor() instanceof AggregationProcessor);
  }
  @Test public void testExecuteWithNullContextThrowsNpe() {
      assertThrows(NullPointerException.class, () -> processor.execute(null));
  }
  @Test public void testCanInstantiate() { assertNotNull(processor); }
  ```
- **严重程度**: P2
- **现状**: 3 个 JOIN processor 测试类共 9 个测试全为 instanceof/instantiate/NPE-on-null；execute() 的正常执行路径、JOIN 路由选择、side 校验在单元层无断言（真实保护仅存在于 TestAggregationExternalJoinAndPagination 等 e2e 层）。
- **风险**: 把任一 processor.execute() 改为恒返回空结果，以上测试全部仍通过；单元层完全无法捕获 JOIN 分派逻辑回归，e2e 失败定位成本高。
- **建议**: MR2 为 3 个 JOIN processor 补真实执行用例（复用 memoryGroupBy 直测模式或 mock context 范式）。
- **信心水平**: 高（已验证断言集合与 execute() 行为无交集）
- **误报排除**: 非"测试少"泛论——断言与行为零交集属结构性浪费，且同包有正确范式可对照。
- **复核状态**: 未复核
- **修复归属**: MR2

### [P2-MA4-303] 分页测试只验行数不验行集：offset 语义无保护

- **信心水平**: 高（offset 被忽略时测试仍通过的逻辑验证）
- **误报排除**: 具体指出"offset 被忽略"真实 bug 场景无法捕获，非泛泛要求更多测试。
- **复核状态**: 未复核

### [P3-MA4-305] sql quality not_null 只验 status 不验统计值

- **信心水平**: 中-高（同文件 volume 用例有 actualValue 断言可对照）
- **误报排除**: 以同文件 volume 用例断言强度作对照，指出不一致。

### [P3-MA4-306] entity expression 聚合断言 `>= 0` 过弱

- **证据片段**:
  ```java
  Object v = getIgnoreCase(row, "EXPRSTATUS");
  assertNotNull(v, ...);
  assertTrue(toLong(v) >= 0, "expression SUM(col+col) must be non-negative: " + row);
  ```
- **严重程度**: P3
- **现状**: SUM(VERSION+VERSION) 真实值应=2×ΣVERSION，断言仅要求 ≥0；实现恒返回 0 也通过。

- **建议**: 先 countRows 求和再 assertEquals 精确值（同文件时间分桶已有精确断言模式可复制）。
- **信心水平**: 高（断言与可实现错误结果 0 不冲突）
- **误报排除**: 有同文件精确断言用例作对照，属断言强度选择而非数据不可精确。
- **复核状态**: 未复核
- **修复归属**: MR2
