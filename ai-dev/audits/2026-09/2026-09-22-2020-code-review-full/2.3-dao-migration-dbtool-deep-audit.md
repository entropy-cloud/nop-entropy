## 维度面结论

### JDBC 执行面（dim04+09，独立复核：18 保留 + 2 降级 + 1 驳回立案）

- 正结论：异常转换链完整（vendorCode/SQLState→JDBC4→UNCATEGORIZED 兜底）、资源管理 finally 双关、分页方言分支与声明一致、marker 安全链闭合、seq Snowflake 并发正确、shard/coderule 纯 SPI 无缺陷面。
- **P1-2.3-001（dim04-01）**：callFunc 参数化调用绑定偏移——`registerOutParameter(1)` 后 marker 从位置 1 起绑，带参 `{? = call f(?)}` 必然失败；H2 驱动级探针实证（`Parameter "#3" is not set`；正确绑定返回 7）；全仓 main 零调用方+唯一测试零参掩盖；javadoc 契约与实现直接矛盾。
- P2×4：LockOption 参数被完全忽略（READ/WRITE 同 SQL、timeout 死参数——live 仅 WRITE 被调用故降级）；executeStatement 的 rs 恒 null 死 close+cancel 回调注册后永不移除；DaoMetricsImpl.endQuery 失败路径 readCount=-1 递减全局计数（同类方法均有 >0 防护）；executeStatement 成功路径读数恒 0（getResultSet() 二次调用新建 wrapper）。
- P3×13：异常翻译门控（errorCode==0 且 SQLState==null 才启用——duckdb 启动建表链依赖消息正则，驱动升级即断）、allowed-names 写 initialSize 实受 initialValue、占位 SQL 翻译、方言发现永久缓存、tryExistsByTemplate 吞 RuntimeException、Hikari initialSize 静默忽略、SQL.begin 丢 loc 元数据、JdbcDataSet 异常无现场、callFunc OUT 类型硬编码 VARCHAR（与 001 合并修复）、元数据探测通配假阳性、SqlDataTypeMapping locale 不对称、空串转 NULL 三写路径不一致、分页死代码防御链。

### 事务与批量面（dim14-txn，独立复核：13 保留；check2 P1×2 already-fixed）

- 正结论：forceTxn 先 commit 后回调、flush 全出口 finally 兜底、REQUIRES_NEW 失败不污染注册表、注册表两参 remove、拦截器链无吞异常（抽验 6 项全过）。
- P2×4：同步 rollback 吞掉子事务回滚失败（与 rollbackAsync 传播语义不对称）；REQUIRED 打开「已注册未打开」事务失败后 rollback no-op（metrics 漏计+外层 SUPPORTS 僵尸化；**疑似涵盖 P3-2.1-028，移交对账归并**）；TxnState fallback 分支传播语义失效（多数据源装配下四传播行为随不相关事务活动非确定漂移）；**SpringTransaction doClose 对未完成事务执行 commit（违反 ITransaction「未 commit 则回滚」承诺）+ getConnection 惰性自动开 REQUIRES_NEW（违反两处注释承诺，每条事务外 SQL=一次独立 Spring 事务）**——升级条件在案（生产确认启用 Spring 桥即升 P1）。
- P3×9：supportBatchUpdateCount 零方言启用、-2 透传与注释矛盾、指标四处失真、commit 前置失败破坏 onBeforeCompletion 契约、async 模板清理异常顶替、JdbcTransaction.getConnection check-then-act、endQuery 无正数保护、rollback 入参三套语义、探活配置双工厂静默丢弃。

### 迁移与 dbtool 面（独立复核：25 保留 + 3 降级；check2 P0×2 already-fixed）

- 正结论：执行链全连通（发现→排序→过滤→执行→历史→repeatable/checksum→回滚声明式路径）、escapeSQLName 注入闭合（实测 `a"b; DROP TABLE x` 双写转义）、VersionComparer 排序健全、失败迁移可重试、DataBaseUpgradeInitializer 门控正确。
- P2×11：**方言缺口族（5 条统一 P2）**——dropIndex mssql 生成非法 SQL（缺必需 ON table）、布尔 TRUE/FALSE 与裸日期字面量 Oracle/MSSQL 必败、renameTable 无 mssql 分支（`ALTER TABLE RENAME TO` 非 T-SQL）、alterColumn mssql 把 DEFAULT 拼进 ALTER COLUMN、escapeValue 不处理反斜杠（Windows 路径破裂 MySQL 语句）；contexts 整串 equals（csv 多值永不匹配，反向隔离静默失效）；type=REPEATABLE/runOn 声明不接线（历史记 VERSIONED）；alterColumn.newColumnName 等四字段静默吞掉且历史记 success；JdbcMetaDiscovery 14 个 jdbcTypes 未映射→discover 全库路径 NPE；**recordMigration 写历史失败→已执行未记录→每次启动重执行数据变更确定性翻倍**（description>500 实测三环闭合）；同 version 重复声明零检测（双文件全执行、isSuccess=true）。
- P3×14：xdef 枚举注释大小写漂移、MigrationExecutor 死类+弱 checksum 地雷、rollback 仅允许 10 种 change 与引擎不对称、5 个零使用错误码、IndexExistsChecker 错用错误码、NO_SQL_FOR_DIALECT 缺参数、dbtool-web 空壳标定（归属建议：移出构建或注明占位）、discoverColumns 零列表防御、历史表并发竞态、errorMessage 从不持久化（失败原因彻底丢失）、scanner 不递归子目录且文件名纯装饰、generateRollbackSql/supports 死 API、CreateIndexExecutor 空列名非法 SQL、ERR_DB_MIGRATION_EXECUTION_FAILED 码-参数错位。
