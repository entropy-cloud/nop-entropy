## 三维度结论

### 维度 01 依赖图与模块边界（组内包级口径）

- 包间边 163 条（24 包互间 121 + 根类相关 42），覆盖 896 Java 文件。**compile/parse/ast→exec/backend 轴向单向无环**（compile→exec 94 条单向、ast 无 exec/backend 出边）；backend→exec 单向干净，SPI 由下游 xlang-java/truffle 经 META-INF/services 注册（正结论）。

- api 包纯净性不通过但**收敛可行**：`IXLangCompileScope` 签名暴露实现类型，下游破坏半径实测仅 1 个下游文件（P2-1.2-002/006）。

- >1500 行手写文件 4 个（TypeInferenceProcessor 2096 / SimpleStdDomainHandlers 1957 / BuildExecutableProcessor 1719 / XLangSemantics 1627），**逐个解剖后均为单一职责，裁定全部不拆**（独立复核维持）；重复度 Jaccard 全仓扫描阴性（0 对 ≥0.25）——模块已把重复骨架系统性移入生成物。

### 维度 05 生成管线完整性（解析→编译→执行链口径）

- **主链全连通（端到端正结论）**：`XLangParseTreeParser.doParse:20` → `AbstractParseTreeParser.parseFromText:56` → `XLangASTBuildVisitor.visitProgram` 产出 AST → `XLangExprParser.buildExecutable:61` →（可选 TypeInferenceProcessor，配置门控默认 off）→ `BuildExecutableProcessor.processAST:81`（生成式 switch 分派 + 硬编码链，未知节点 `defaultProcess:297` fail-fast）→ `ExprEvalAction.invoke:45-52` → `XLang.execute:47` choke point → `EvalBackendRouter.executeAdjudicated:87`（绑定直通/降级直通/决策树）或注册表空 fast-path。`_vfs` 注册面 6 个 register-model 与消费点逐一命中。
