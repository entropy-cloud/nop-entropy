## jq 面（独立复核：18/18 保留）

### 结构与基线（正结论）

- ast→runtime 零 import（sealed AST + visitor 单向）；公开 API 收敛 `JqEngine.compile/apply`，全仓消费方恰 1 个（JqToolExecutor，与 module-groups 记载一致）；pom 依赖全部实际使用。
- 覆盖面：非 comment 块 447 = 挂载 430 + 跳过 17（12 模块系统块合规 Non-Goal + 5 官方 %%FAIL IGNORE）；surefire XML 双口径一致；模块合计 560 测试全绿。
- 部分求值：8 项抽查全对（多输出有序流/生成器基数/类型错误必抛）；halt 语义 6 条专测锁定。

### 缺陷面

- **P1（jq-13/16 合并）工具接缝资源耗尽**：combinations（JqBuiltins:1823-1836）/constructObjects（JqExecutor:574-576）/interpParts（:596-598）/repeatString（:963-975）4 类叶节点无 `checkOutputLimit`（预算在 10 处设防点——设防是设计意图，绕过属契约洞）；`[range(25)]|map([0,1])|combinations|length` 47 字符在 -Xmx128m 630ms OOM、-Xmx2g 6.0s OOM；`"a"*1e9` 222ms OOM。jq 是 ai-toolkit 默认 bean（ai-toolkit-defaults.beans.xml:50）；复核关键校勘：真实默认链为 Default* 三件套（非 NoOp/PassThrough opt-in）但结论更强——**trusted/untrusted 两信任分支下 jq 均自动批准无人工门禁**（jq 不在 HIGH_IMPACT_TOOLS）；agent 层 orTimeout(300s) 不取消底层计算（接缝零处引用 cancelToken）→ 僵尸计算；OOM 进程级 collateral（探针采样线程死于 OOM）。降 P2 触发条件（反事实）：若 jq 非 agent 可达默认工具——两部署事实已独立核实排除。
- P2×8（jq-02/03/07/08/12/14·19/17/18）：错型静默空流簇（`3|sort`/`3|max`/`3|to_entries` 不报错、getpath 穿透返回 null——jq 均报错；isnan 子例经复核校勘：官方返回 false 非 error）、对象比较插入序 bug（`{b:3,a:1}<{a:2,b:2}` 本机 jq-1.7.1→true、nop-jq→false，复核升级证据）、%%FAIL 空洞化（接受任意 Exception+OOM/SO 零原因校验）、applyPartial 吞全部 RuntimeException 掩蔽实现 bug、env/$ENV 全进程变量直通 agent（全 toolkit 唯一 System.getenv 直通面——BashExecutor 三重沙箱先例存在却未接线）、constructObjects/interpParts 叶节点无预算（128m 560ms OOM）、合法巨结果无体积上限（toolkit 直连无 truncation）。
- P3×9：IJsonQuery 恒值 legacy 方法、解析位置报 token 序号非字符偏移、`$$foo` 双 $、input 耗尽 error value "break"、算术错误嵌完整值、深嵌套 1000-2000 层 SO（Error 逃出 catch(Exception)、agent 层收敛 error=null 零诊断）等。

### 消费接缝

JqToolExecutor（nop-ai-toolkit）无超时/cancelToken 忽略；`catch(Exception)` 不捕 Error。修复点定位：4 类叶节点各一行 `env.checkOutputLimit()`（`limit(1;combinations)` 探针证明 sink 增量生效、修复不破坏 limit 语义）；env 修复路径=env-supplier 注入 + context.getEnvs()（沙箱机制在位未接线）。
