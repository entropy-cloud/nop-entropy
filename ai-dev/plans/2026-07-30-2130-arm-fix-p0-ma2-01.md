# Fix P0-MA2-01: Dual ORM Source File Drift

> Plan Status: active
> Last Reviewed: 2026-07-30
> Created: 2026-07-30
> Source: `ai-dev/audits/2026-07-30-2130-arm-MA2.1-2.4-nop-ai-orm-biz.md`
> Finding: P0-MA2-01

## Purpose

Eliminate the dual ORM model source ambiguity in module `nop-ai` by establishing `nop-ai.orm.xml` as the single canonical source and archiving the legacy `ai-gen.orm.xml`.

## Current Baseline

- `nop-ai/model/` contains two ORM source files: `nop-ai.orm.xml` (1403 lines, 21 entities, fully audited) and `ai-gen.orm.xml` (364 lines, 14 entities, missing audit columns, incompatible dict values)
- Production `_vfs/nop/ai/orm/_app.orm.xml` uses `orm-gen:DefaultPostExtends` / `orm-gen:DefaultGenExtends` for codegen — no direct `x:extends` reference to either model file
- The audit (`P0-MA2-01`) confirms `nop-ai.orm.xml` is the correct, comprehensive version
- `ai-gen.orm.xml` is referenced by 6 codegen task/template files in `nop-ai-coder` (out of scope for this plan — see Non-Goals)

## Goals

- Archive `nop-ai/model/ai-gen.orm.xml` with a clear header comment explaining its status
- Verify production ORM reference chain does not depend on `ai-gen.orm.xml`
- Confirm `./mvnw build + test` passes with only `nop-ai.orm.xml` as canonical source
- Update `arm-index.md` to reflect the fix

## Non-Goals

- Updating the 6 codegen task/template files in `nop-ai-coder/` that reference `ai-gen.orm.xml` — these serve a different purpose (scaffolding new projects) and require separate assessment
- Fixing the other audit findings (P1-MA2-02 through P3-MA2-11)
- Removing `ai-gen.orm.xml` from the repo — only adding an archive header

## Scope

### In Scope

- `nop-ai/model/ai-gen.orm.xml` — add archive header comment
- `nop-ai/nop-ai-dao/src/main/resources/_vfs/nop/ai/orm/_app.orm.xml` — verify reference chain
- `arm-index.md` — mark P0-MA2-01 as fixed
- Build/test on `nop-ai` module

### Out Of Scope

- `nop-ai/nop-ai-coder/` template/task references to `ai-gen.orm.xml` (6 files)
- Other P0/P1 findings from the same audit
- Structural removal of `ai-gen.orm.xml` from the repo
