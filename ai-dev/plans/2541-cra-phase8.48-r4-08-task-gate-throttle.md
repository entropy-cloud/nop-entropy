## Risks And Rollback

- **W-04 重入检测误伤风险（本批最高交互面）**：显式共享 keyExpr 可能存在**有意嵌套**用法（外层 throttle 限制总量+内层同 key 自限流）——重入检测若一刀切拒绝会破坏存量合法模型；裁定 A 须显式推演「有意嵌套」语义（文档声明不支持+硬失败升级注记 vs key 集作用域分级）并落 owner doc 升级注记；缺省双路径（call-task/call-step）key 形态核实错误会漏检或误检；回滚 = 检测分支单点可逆（摘除 key 集记录与判定），红④ 防「检测存在但嵌套仍通过」退化；C10-002 两缺省路径覆盖为回归门。
- **W-03 失效钩子与 permit 池完整性冲突风险**：模型热更新清除闸门若不判在途持有者即销毁 semaphore 会导致持有者 release 到已替换实例（permit 池分裂——plan 364 驱逐裁定红线）；「在用计数归零后替换」形态与 2514 permitsFull 判据的联动推演漏项即破坏 2514 产物；回滚 = 失效路径单点可逆（摘除钩子恢复纯文档声明），红③ 防「钩子存在但热更新仍不生效」退化；2514 治理产物 git diff 零重开为红线。
- **W-06 Throwable 收宽过宽风险**：catch(Throwable) 若吞 OOM/StackOverflow 不 rethrow 会把致命错误转为业务失败——rethrow 必然性核验（rule 24）+C8-009 SOE 连锁注记边界随裁定 B；回滚 = catch 分支单点可逆（恢复 catch(Exception)），红⑥ 防「收宽存在但 Error 仍悬挂」退化；plan 349 取消兜底钉族为回归门。
- **W-07 取消传导的副作用风险**：bindCancelToken 深入 body 内层链可能中断不可安全取消的外部调用（DB 事务中段取消）——传导边界（哪些链段可安全注入）随裁定 B；permit 归还时机改造若改早释为 body 绑定会延长占用（过载窗口变宽）——联合推演落款；回滚 = 传导分支单点可逆（恢复竞速终结原形），红⑦ 防传导存在但幽灵 body 仍续延退化；`TestSuspendSemantics`/`TestChildRuntimeCancelPropagation` 为回归门。
- **W-08 监视器收敛的死锁/性能风险**：`synchronized(stepState)` 若与 taskState 监视器嵌套获取序不当会引入 ABBA（2514 裁定②锁序图联动评审漏项）——锁序唯一分支+两驱动验证缺一不可；热点步骤高频终态写点的锁竞争退化（吞吐回退）需评估；回滚 = 收敛分支单点可逆（恢复无锁守卫），红⑧ 防互斥存在但交错仍产生混合状态退化；364 [05-01] 守卫语义钉为回归门。
- **W-01 remind 半区同构改造的恒空集风险**：remindTime 无引擎写入点=remind 半区退避在当前 live 无真实触发面——退避逻辑空转（hollow 形态风险）或测试需注入 remindTime 行（模型缝）；gauge 命名与 2514 gauge 纪律一致性；回滚 = 退避分支单点可逆（恢复仅 LOG.error），红① 防「退避存在但失败仍每轮重扫」退化+接线断言防空壳[2515 先例]；`testScanDueTasksIgnoresCurrentStepStatusRace`/TestWfTaskScannerFencing 为回归门。
- **W-05/W-09/W-10 校验链升级破坏存量模型风险**：构建期硬失败为破坏性约束（存量模型 maxConcurrency=0/maxWait<0/sleep 大值/fork-n 大 count 升级后装配即 fail-fast）——owner doc 升级注记义务（2514 sync×executor 先例形态）+缺省值论证；回滚 = 校验分支单点可逆（摘除分支恢复装配通过），红⑤⑨⑩ 防校验存在但非法值仍装配退化；`TestFirstClassConfigValidation` 扩展腿为回归门。
- **W-12 封顶缺省语义选择风险**：maxRetryDelay=0 缺省「不封顶」若收敛为封顶会改变存量长退避行为（用户可见面）——维持不封顶+文档声明 vs 收敛封顶+升级注记随裁定 F；事务解耦定时器形态须守 2497 §七（timer 只触发）否则调度槽纪律回归；回滚 = 封顶/解耦分支单点可逆，红⑫ 防封顶存在但固定 delay 仍未封顶退化；task 侧 RetryPolicy 对照为回归门。
