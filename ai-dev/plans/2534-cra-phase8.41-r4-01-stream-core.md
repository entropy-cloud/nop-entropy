## Risks And Rollback

- **W-06/W-12 统一设计回退风险**：always-inline 推广改变 shutdown 态行为（丢弃→caller 线程执行）——commit I/O 在停机派发线程上执行的一次性代价为设计内取舍（CC-17 先例已裁定该语义）；与裁定⑤ 层4 复核的组合行为须测试覆盖（TestStandbyDegradeCancelsInFlightPersist 零回退锚+新钉组合场景）；回滚 = handler 单点可逆（恢复 CallerRunsPolicy/原 policy 分支），红③⑦ 防「handler 改了但 execute 点未接线」退化。
- **W-02 epoch 治理行为变更风险**：重复槽位分支从「静默忽略」变为「置换/拒绝+上报」——恢复路径生产行为变更声明（owner doc 缺口形态下落设计文档+roadmap 注记）；CC-02 同款治理降低发明风险（selectDisplacedTask 复用）；回滚 = 分支守卫单点可逆，红① 防「守卫存在但上报未接线」退化。
- **W-09 mailbox 交接的可用性风险**：任务卡死/长 GC 时 HTTP 查询从「立即返回（可能错误数据）」变为「typed 超时」——超时预算值与重试语义为裁定 D 定夺面；监控轮询语义变化落 owner doc；回滚 = 交接层单点可逆（退回直读+文档降级备选③需重走裁定），红⑤ 防「mail 投递存在但 handler 未走交接」退化。
- **W-14 语义变化风险**：release 后 meter 条目消失改变 Prometheus 抓取序列行为（恒 NaN 序列→序列消失）——下游看板/告警规则如依赖 NaN 哨兵需迁移；owner doc 同步为 Phase 3 硬性项（裁定 E 强制裁定）；单 jobId 复用场景由构造自然重建（键空间封闭论证落裁定）；回滚 = release 形态单点可逆（保留 holder 置空+恢复 owner doc 声明），红⑧ 防「remove 存在但 holder 泄漏」退化。
- **W-11 取消语义风险**：finally cancel 遍历改变中断后任务终态（自旋→CANCELED 终态）——既有 LOCAL E2E 测试（TestEventTimeWindowE2E 等）零回退锚（正常完成路径不经取消分支）；cancel 与 bounded-await 守卫（裁定②）的组合次序（await 超时 abort vs interrupt cancel 两条终态路径）归裁定 D 论证；回滚 = cancel 遍历单点可逆，红⑥ 防「cancel 存在但 shutdownNow 先行中断丢失」退化。
- **W-13 抑制覆盖面风险**：窗口聚合可能掩盖「每次失败对象不同」的故障形态——覆盖集清单逐点核定（裁定 E）+ 恢复 cleared 语义保证故障结束可见；elector INFO→WARN 升级建议（C7-014）随裁定；回滚 = 抑制载体单点可逆（内联 lastLoggedAt 门控最小形态），E2 泛在钉防「抑制存在但计数失真」退化。
- **基线 F1 flake 与 E3 噪声风险**：runtime F1（负载 flake 已 solo 绿归因）+ debezium docker 抖动（2510 先例）为 E3 主要噪声源——按勘误 4/5 判据处置（并发通道复现→solo 三联绿归因→维持；禁静默重跑）；format-avro/sql/fraud-example 三模块基线未覆盖（反应器跳过）——Phase 3 补齐覆盖后其签名作为首验基线登记。
- **上游链环境噪声风险**：批行 `-am` 通道触达上游闭包大（勘误 5 五已知面集——面④ 已解除）——三联裁定/已解除基线处置留痕，不得静默重跑或跳过；分解通道全量 ~7min 可接受为日常迭代通道。
