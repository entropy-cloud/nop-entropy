把 MA4 审计中剩余未收口的公开 API 文档债务项收口：18 个 deprecated 类/接口/枚举补具体迁移指引（MA4.2-07）、30+ 个公开接口方法补 javadoc（MA4.2-10）、7 个小型公开 API 接口补类级 javadoc + 2 个核验（MA4.5-009）、IFileOperator deprecated 消息语言与全库一致性（MA4.5-008）。全部为 javadoc/注释层面的文档补全，零行为变更，低风险；受益者是框架 API 的外部消费者（AI agent 与集成方）。

## Goals

- 18 个 deprecated 类/接口/枚举的 javadoc 从泛化消息改为指明具体替代类型（或明确裁定"无直接替代"并注明保留理由）
