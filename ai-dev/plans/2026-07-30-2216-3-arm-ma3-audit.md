## Scope

### In Scope

- MA3.1: All nop-ai modules — dependency direction compliance (DAG), Maven dependency declarations vs actual imports, architecture baseline compliance (per `docs-for-ai/01-repo-map/module-groups.md`)
- MA3.2: Security annotations, data permissions, field-level access control, app-layer command validation, gateway conversion security
- MA3.3: BizModel transaction boundaries, chat service async patterns, `@BizQuery`/`@BizMutation` transaction semantics
- MA3.4: `NopAiException` usage, `ErrorCode` enums, `Logs/Errors.java` files, error message patterns
- MA3.5: Cross-module API version compatibility (api→core→agent→toolkit interface contracts)
- `ai-dev/audits/arm-index.md` — update with findings

### Out Of Scope

- Code fixes (deferred to MR2)
- AI/LLM specific risk audit (MA6 — separate plan)
- MCP modules
- Code quality audit (MA4 — separate plan)
