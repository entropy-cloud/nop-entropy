## Risks And Rollback

- **W-01 tag 键形与基数风险**：tag 唯一化改变 meter 键空间——高并行度作业 tag 组合数膨胀（scrape/存储面）+身份源注入触 backend 构造签名——键形与身份源归裁定 A 定夺（对照 R5-CEP-03 双标签正例与 8.41 W-15 稳定键 registered deviation 先例）；回滚 = tag 参数+remove 分支单点可移除（恢复 Tags.empty()+无 remove），红① 防「tag 存在但去重仍吞注册/close 无摘除」退化。
- **W-02 回落语义变更风险**：decode 侧从「静默回落」变为「typed 失败或限频 WARN」——schema 演进读取故障窗口行为变化（运维可见性提升正是修复目标，但 owner doc :118 声明对齐与消费方兼容性归裁定 C 定夺）；回滚 = 负缓存/typed 分支单点可逆（恢复静默回落），红② 防「负缓存存在但回落仍无信号」退化。
- **W-03 close 接线漏点风险**：close 通道存在但宿主接线遗漏=空壳（Anti-Hollow 红线）——接线归宿归裁定 C 定夺（client/透传/宿主三层逐层定夺）+红③ 装配-停止循环断言承载真接线验证；回滚 = close 分支单点可逆，红③ 防「close 存在但无人调用」退化。
- **W-04 上界误杀风险**：缺省上限过小可拒绝合法大 epoch（大促/长 barrier 窗口）——缺省值与配置化归裁定 D 定夺（对齐裁定② 参数纪律与 R01 §3.1 缺省值惯例论证）；spill 形态如采涉 temp 文件面语义（与 C6-007 孤儿清扫 R4-04 面相邻——禁顺带登记）；回滚 = 上界检查单点可移除，红④ 防「旋钮存在但转存未守卫」退化。
- **W-05 流式迁移的正确性风险**：单遍迭代逐行写回依赖 iterator 快照语义（迭代中写同 CF）——RocksDB 隐式快照语义论证归裁定 A（或分批形态规避）；迁移失败的中间态一致性（部分迁移后失败）与 2511 双路径迁移不变式（schema header/fail-fast）兼容性核对；回滚 = helper 单点可逆（恢复双列表收集），红⑤ 防「流式存在但三实例路径未全覆盖」退化。
- **W-06 OS 锁超时的语义风险**：tryLock 轮询期限过短可误判健康竞争为挂死（跨 JVM 正常慢提交被 typed 失败）——期限值与重试语义归裁定 D 定夺；锁顺序 JL→FL 纪律零改写为硬红线（重入/反转即正确性回归）；OS 锁面验证盲区（外部进程注入难）由红⑥ 结构钉/变异论证分支承载（禁伪绿）；回滚 = 超时分支单点可逆（恢复 lock()），红⑥ 防「超时存在但 jvmLock 仍不可中断」退化。
- **W-07 清理点时序风险**：remove 条件（ledger 空+state 全清）与 reconcile 一次性语义的组合——清理过早可致 reconcile 重入（重复对账副作用面）——条件形态归裁定 B 定夺；R01 对齐解读如采 SSOT 行则走 §3.4 link-don't-copy（禁参数发明）；回滚 = remove 分支单点可移除（恢复只增），红⑦ 防「清理存在但水位钩子不可见」退化。
- **W-09 耦合校验误报风险**：估算器（estimate-num-keys×速率常数）估算失准可 typed 拒绝合法作业——速率常数配置化与缺省值归裁定 A 定夺（对照 validateUnalignedConfig 先例的 fail-fast 边界）；hashPolicy 缺省值改变完整性语义（new-only/sampled 的取舍声明归裁定）；回滚 = 校验方法+旋钮单点可逆，红⑨ 防「校验存在但两面未同盖」退化。
- **W-10 过载策略行为变更风险**：CEP 匹配缓冲从「无界积压」变为「typed 拒绝/降级」——watermark 停滞场景下任务从 OOM 挂死变为可见失败（行为变更 owner doc 声明+用户指南边界节归裁定 B）；缺省上限过小可拒绝合法长窗口 pattern——缺省值归裁定；回滚 = 过载分支单点可逆（恢复无界积压），红⑩ 防「策略存在但 backing 状态未守卫」退化。
- **W-11 语句超时的兼容性风险**：setQueryTimeout 缺省值过小可中断合法大批次提交（maxBatchSize 分段×慢盘）——缺省值与 checkpointTimeout 同量级论证归裁定 D；部分驱动对 setQueryTimeout 支持差异（部署校验提示形态归裁定）；回滚 = 超时设置单点可移除，红⑪ 防「白盒通过但运行时未生效」退化（白盒+注入双形态）。
- **W-12 字节界误杀风险**：缺省 16MB 量级对二进制大 payload 场景（文档/快照事件）的兼容性——缺省值与降级形态归裁定 D 定夺（对照 maxLineBytes 缺省论证）；双桥行为一致性（同键两模块同缺省）；回滚 = 守卫分支单点可逆（恢复无检查 put），红⑫ 防「守卫存在但双桥未同盖」退化。
- **基线 F1/docker 与 E3 噪声风险**：runtime F1（负载 flake solo 三联绿归因在案）+ docker 双 E2E 慢跳过/fork 超时（2534/2535 先例）+ debezium/connector docker 门控为 E3 主要噪声源——按勘误 4/5 判据处置（并发通道复现→solo 三联绿归因→维持；禁静默重跑）；本批站点集中在六连接器/cep/format 模块（docker 门控测试面与批内工单零缺陷面交集——TestDebeziumReal* 为功能连通面非本批缺陷面）。
- **上游链环境噪声风险**：批行 `-am` 通道触达上游闭包大（勘误 5 已知面集——面① solo 三联裁定先例）——三联裁定/基线行为处置留痕，不得静默重跑或跳过；分解通道全量为日常迭代通道。
