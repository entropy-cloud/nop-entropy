## Purpose

External consumers can adopt nop-treesitter without reading source: module page in docs-for-ai, complete Javadoc on public classes, a wiki-style entry, and INDEX routing (DOC-01..04).

## Current Baseline

- Items 2-13 `done`; 383 tests green; module public surface: TSParser/TSTree/TSNode/TreeSitterException + language/lexer/parser(glr, incremental)/subtree/query/scanner/cursor/util/provider/biz packages; integration story (item 12) and perf story (item 13) already documented in `nop-treesitter/README.md` and `nop-treesitter/docs/perf-tuning.md`.
- Javadoc scan (2026-09-10): every public class carries class-level Javadoc except `biz/TreeSitterErrors.java` (constants interface, `FileErrors` precedent has none either — verify against the precedent before adding).
- `docs-for-ai/03-modules/` holds per-module owner docs (`nop-file.md` style: 功能概览/快速开始/...); `docs-for-ai/INDEX.md` routes them in the By-Task table; `docs-for-ai/04-reference/source-anchors.md` carries implementation anchors.
- Repo rule: after touching `docs-for-ai/` or `ai-dev/`, `node ai-dev/tools/check-doc-links.mjs --strict` must exit 0.

## Goals

- **DOC-01**: `docs-for-ai/03-modules/nop-treesitter.md` — architecture overview, public API, grammar registration (built-ins + ServiceLoader), GraphQL/IoC usage, performance characteristics (linking perf-tuning.md), recovery semantics summary.
- **DOC-02**: Javadoc on every public class in `io.nop.treesitter.*` (close the `TreeSitterErrors` gap if the precedent check warrants; verify the rest by script).
- **DOC-03**: `nop-treesitter/docs/wiki.md` — wiki-style entry (short orientation page linking README/perf-tuning/docs-for-ai page).
- **DOC-04**: `docs-for-ai/INDEX.md` By-Task entry for nop-treesitter + `docs-for-ai/04-reference/source-anchors.md` anchors for the module's key entry points.

- Wiki platform integration beyond the `docs/wiki.md` file the roadmap offers as the alternative.
