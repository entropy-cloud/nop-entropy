## Purpose

为 tree-sitter-go 构建 blob 并通过上游 corpus 验证（≥95%），使 nop-treesitter 运行时可解析 Go 源码，解锁 nop-code N5.4（Go 语言扩展）。

## Current Baseline

- 运行时全能力在档（roadmap 1–17 done）：GLR/错误恢复/query engine/增量解析；6 个 blob 在档（json/java/js/ts/tsx/python），blob 格式 v4。
- `Ts2Java <parser.c> <out-blob>` CLI 在档（`io.nop.treesitter.codegen`）；`tree-sitter-go/src/parser.c`（v0.25.8，LANGUAGE_VERSION 15，EXTERNAL_TOKEN_COUNT 0——无 scanner.c）本地可用。
- corpus 范式：`CorpusUtil.read` + `XCorpusTest`（`ADJUDICATED` 列表记录已知分歧 + root cause；先例 `PyCorpusTest` 98.3%、`JsCorpusTest`）。
- compat 包装范式：`TreeSitterPython implements TreeSitterLanguage`（classpath blob + scanner factory）；Go 无 scanner，包装更简。
- 语义校验规则（roadmap 横切）："If a grammar has <95% pass rate, that's a roadmap item to fix the runtime, not a 'known failure' to ignore"。

## Goals

- G1：`src/main/resources/grammars/go/tree-sitter-go-blob.bin`（Ts2Java 产出）。
- G2：vendored corpus `src/test/resources/upstream/grammars/tree-sitter-go/test/corpus/`（上游原样，不合成）。
- G3：`GoCorpusTest`：全 corpus section 跑通，pass rate ≥95%；分歧逐条 `ADJUDICATED` 登记 root cause（若率 <95% 则视为 runtime 缺陷回修，不在本 plan 内豁免）。
- G4：`TreeSitterGo` compat 包装（无 scanner factory）。

## Non-Goals

- Rust/C# grammar（条目 19/20 另立 plan）。
- Go 语言提取器/nop-code 集成（N5.4 承接）。
- query/highlights scm for Go。
- 运行时行为变更（例外：corpus 率 <95% 暴露的 runtime 缺陷，以及加载层缺陷——B1 审查实证 go blob 触发 `Language.decode` 校验拒绝，属修复义务而非 scope 扩张）。
