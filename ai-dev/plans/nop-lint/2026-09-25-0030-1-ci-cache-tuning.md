## Purpose

design 11 Phase 4 三件收口，按 live 现状如实拆解：
1. **CI 缓存工件化（实现）**：CLI `check --cache <file>`——增量结果缓存（eslint --cache 同型）：以 (文件内容 hash + 规则集 hash + profile) 为指纹，命中文件直接回放缓存诊断（跳过解析与匹配），未命中 lint 后写回；`RunSummary` 增加 `cacheHits` 计数（design 11 §4 "命中率进入 LintStats"）。缓存文件为单一 JSON 工件（CI 流水线 artifact 保存/恢复）。**CST 磁盘缓存在 v1 显式不做**（tree-sitter CST 序列化无平台支持，指纹跳过整文件已获主要收益），记 design 11 §4 增注。
2. **编辑器 watch 集成（裁定：已交付）**：item 41 的 LSP 服务器即编辑器 watch 面（文档同步 + 诊断推送 + 增量解析）；design 11 §8 的 "编辑器 watch 集成" 以 LSP 交付记录收口，无新增实现。
3. **GraphQL fast 档调优（测量 + 记录）**：`Lint__checkSource` 端到端延迟 JMH 基准（graphql 模块 test 作用域 jmh，同 core 先例形态），对照 design 11 §6 的 <100ms 预算；达标则调优 = 测量记录（引擎单例已暖），超标则定位修复。

## Current Baseline（live 核对 2026-09-24）

- CLI：`NopLintCli`/`CheckRunner`/`CliOptions`/`RunSummary` 全参数面（items 18/25/27/39）；无任何缓存面。
- LSP：`NopLintLanguageServer`/`NopLintLspLauncher` 已交付（item 41，R2 复审 APPROVED）。
- GraphQL：`NopLintBizModel` 懒单例（registry + FAST 引擎 + 规则集一次加载——item 38 Decision 6），13+ 测试；无延迟基准。
- perf 锚点：engineLint 0.002±0.001 / parseAndMatch 0.001±0.001 s/op（perf-baseline.md）。
- 设计要求（§4）："缓存目录随仓库/流水线工件保存；命中率进入 LintStats"。

## Goals

1. **`--cache <file>`**（CliOptions 解析 fail-closed + CheckRunner 缓存面）：指纹 = SHA-256(文件 bytes) ⊕ SHA-256(规则集序列化) ⊕ profile ⊕ fixMode ⊕ **生效 --rules 过滤的排序 id 列表（R1 Major 1——否则同缓存工件换 --rules 静默回放错误诊断）** ⊕ 缓存格式版本字段（R1 Minor 9——引擎语义修复后旧工件失效）；命中回放缓存诊断（进报告与退出码统计），未命中 lint 后写回。缓存写回为原子（temp+move）。**损坏缓存文件 fail-closed 报错（R1 Minor 10）**，非静默忽略重填。**注意基线语义**：v1 裁定 `--cache` 与 `--baseline` 族互斥（fail-closed 解析错误），与 `--fix`/`--fix-dry-run` 互斥（缓存诊断不能驱动 fix multipass）。**暖跑恒等声明限于诊断流**（R1 Minor 3）：命中文件的 engine stats 行（rulesExecuted/xscript）允许归零，cacheHits 行存在；`--cache` 未激活时 cacheHits 不渲染（R1 Minor 4）。
2. **`RunSummary.cacheHits`** 计数 + ConsoleReporter 汇总行（"cache: N hits"）+ json/其他机器格式不动（诊断流不变）。
3. **GraphQL 基准**：`nop-lint-graphql` test 作用域 JMH（jmh-core + generator，版本对齐 core 基准 1.33）——`graphqlCheckSource` 基准（暖单例 + 中型语料），对照 <100ms 预算；结果入 perf-baseline.md。
4. design 11 §4/§8 增注（缓存 v1 面 + watch 集成收口裁定）。

## Non-Goals

- CST 磁盘缓存（序列化无平台支持；指纹跳过整文件为 v1 收益面）
- L2 类型缓存磁盘化（design 11 §4 第三层；L2 面归 tsc/symbol solver 后续批次）
- `--cache` 与增量 range sync、分布式缓存一致性
- 客户端插件打包
