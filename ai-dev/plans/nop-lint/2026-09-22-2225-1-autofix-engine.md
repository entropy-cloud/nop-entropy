# Autofix 引擎（roadmap item 25）：template fix + 冲突合并 + multipass ≤10 + dry-run 原子应用

## Current Baseline

以下事实均已对照 live repo（2026-09-22）核实：

- 依赖满足：item 25 deps = item 22（`done`）——诊断管线完备（match → constraints → xscript → suppression → diagnostics），`RuleSetRunner` 携带每个 match 的 `MetaVarEnv`（捕获文本可用），`Diagnostic` 携带 ruleId/severity/message/range。item 24 的 matches/utils 面已落地。
- **fix 字段现状**：design 01 §2 已定义 `fix: {description, template, suggest}` 顶层字段（template 语法 = meta-var 替换，`$VAR`/`$$$VAR` 引用捕获、非捕获标识符字面量保留；suggest=true = 仅建议不参与 --fix），但 xdef/`RuleDslModel`/`RuleDslParser`/`CompiledRule` 均无 fix 面——本 plan 新建。
- 设计权威：design 03 §3（dry-run 只输出 diff；原子写 = 临时文件 + rename；multipass ≤10 每轮重解析、语法破坏即中止并回滚该文件；幂等收敛 = 每轮后诊断数必须下降否则停止；被抑制的诊断不产 fix；冲突 = range 重叠只应用优先级最高者）+ design 04 §7（TemplateFix.compile/apply——fragments + vars + deindent/reindent；Fixer.merge = 按 range[0] 排序 + 贪心合并 + 冲突检测；Fixer.expand 为 🔧 扩展面，本 plan 裁定是否纳入）。
- 引擎接线位：`RuleSetRunner.run` 的非 xscript 分支逐 match 产 `Diagnostic`（`RuleSetRunner.java:97-103`，match 级 `MetaVarEnv` 在此唯一可用）；`SuppressionFilter` 在 `LintEngine.lint` 尾部对 Diagnostic 整体过滤（`LintEngine.java:153-156`）。**fix 载体裁定（审查后定）**：`Diagnostic` record 追加可空 `fix` 字段——fix 在 match 期生成（env 可用）、随诊断被 suppression 整体移除（"被抑制不产 fix" 天然成立，`SuppressionFilter` javadoc 的既有预言与此一致）；`Fix` 自足（replacement 文本 + byte range，序列捕获文本在 match 期已拼入 replacement，应用层无需节点结构）。修复的**应用**（合并/multipass/写文件）属 CLI 层新面。`LintResult` 面不变（fix 随 Diagnostic 走）。
- CLI 现状：`CliOptions`/`CheckRunner`/`ConsoleReporter`/`FileFindings`/`RunSummary` 构成 check 管线；无任何写文件路径——`--fix`/`--fix-dry-run` 全新面。
- 模板引用语法：fix template 的 meta-var 与 pattern 捕获同名（`$VAR`/`$$$VAR`），`SourcePattern.captureNames()/multiCaptureNames()` 已提供声明集（item 22 落地），模板引用未声明捕获须 compile 期 fail-closed（与 constraints 同一口径）。
- 硬约束适用：零平台改动；Wave-2+ 新能力带测试（Minimum Rules #25）；模板引用未声明捕获/空模板/越界形态 fail-closed（#24）；原子写失败不得留半改状态；multipass 不收敛必须停止并如实报告（不得静默丢弃）。

## Goals

- DSL 面：`fix: {description, template, suggest}` 顶层字段进 xdef/`RuleDslModel`/`RuleDslParser`/`CompiledRule`/`Diagnostic`（description 非空必填、template 非空必填、suggest 默认 false；模板引用未声明捕获在 `CompiledRule` 编译期拒绝——捕获集在模式编译后才存在；模板内未声明的 `$TOKEN` 字面量 v1 显式拒绝，转义语法 defer）。
- 组合面 fail-closed（对齐 constraints 先例）：`fix` 与 `xscript` 同规则 → parse 期拒绝（xscript 诊断不经非 xscript fix 分支，模板会被静默丢弃）；`language: XML` 规则声明 `fix` → compile 期拒绝（`CompiledRule.precompiled` 路径不产 fix）；`metadata.autoFixable` 与 `fix` 字段不做强一致校验（裁定不校验，写入文档）。
- `fix/` 包：`TemplateFix`（编译模板 → fragments + meta-var 槽位；per-match apply → 替换文本；`$$$VAR` 序列捕获取**首末捕获节点之间的原始源码切片**——保留逗号/注释最忠实，空序列 = 空串）、`Fixer`（按 range[0] 排序 + 贪心选择 + 重叠冲突检测；优先级口径：跨规则按规则集声明序，同规则内嵌套/相同 range 按 match 生成序在前者优先——"range 互斥"前提不成立，嵌套同形匹配可重叠）。
- multipass 语义裁定（写回 design 03 §3 增注）：不收敛停止时**保留最后成功轮的写盘**（partial progress 如实呈现）；dry-run 在内存中走完整 multipass、输出**原始 vs 最终**单一 unified diff；收敛计数以**参与 fix 的候选诊断数**为准（不含 suppression 元诊断——autofix 删除代码常使邻近抑制指令失效、元诊断反升，按全量计数会假性 nonconvergent）。multipass 每轮全量重编译规则可接受（≤10 轮，编译缓存归性能优化非本 plan）；`--fix` 退出码沿用既有三态（残留 error → 1，全净 → 0），fix 活动不改变退出码口径。unified diff 由手写格式化器生成（复用 `LineIndex` 行换算，不引第三方库）。
- 应用层：`FixApplier` multipass（≤10；每轮：合并选择 fix → 应用 → 重解析 → 语法破坏即中止并回滚该文件 → 重跑 lint；诊断数不下降即停止并计数）；原子写（临时文件 + 原子 move）；dry-run 模式（只产 unified diff，不写文件）。
- CLI 接线：`--fix` / `--fix-dry-run` 选项；`suggest: true` 的 fix 只在 dry-run/报告输出中列为建议、不参与写回；RunSummary 增加 fix 计数（applied/skipped-conflict/skipped-nonconvergent）。
- 抑制交互：被抑制的诊断不产 fix（fix 随 Diagnostic 生成、suppression 整体过滤即连带移除，见 Current Baseline 载体裁定）；fix 产生的新诊断走正常管线（重跑即得）。
- 端到端证明：`--fix-dry-run` 与 `--fix` 对真实临时文件的 e2e 测试（含冲突合并、multipass 收敛、语法破坏回滚三场景）。
- owner docs 回写（design 01 §2 fix 字段落地形态、design 03 §3、design 04 §7 落地注记）+ roadmap item 25 状态回写（draft review 通过置 `planned`，closure audit 通过置 `done`）。

## Non-Goals

- `Fixer.expand`（StopBy 向扩展修复范围）——design 04 §7 标注的扩展能力，本 plan 裁定 defer（无首批规则需要；Successor 随首批 autofix 规则落地时评估）。
- 多行替换的 deindent/reindent——与 expand 同属 design 04 §7 的 🔧 扩展面，本 plan 裁定 defer：v1 替换文本要么是模板字面量、要么是源码逐字切片（$$$ 序列取首末节点间原文），缩进保持原样；自动重缩进属外观优化，Successor 随首批 autofix 规则的真实需求评估（design 04 §7 增注记录该范围裁定）。
- autofix 规则批量与 `--fix` 在 CI 门禁的组合策略（items 29/35/40）；规则库 CHANGELOG（item 42）。
- 编辑器 fix 协议（LSP code action，item 41）；GraphQL 侧（item 38）。
- xscript 产 fix（v1 只有 template fix；report() 自定义 fix 面随 xscript 扩展另行裁定）。
- 模板字面量 `$` 的转义语法——v1 对未声明 `$TOKEN` 显式拒绝（fail-closed），转义语法 defer 到出现真实替换需求时裁定。
