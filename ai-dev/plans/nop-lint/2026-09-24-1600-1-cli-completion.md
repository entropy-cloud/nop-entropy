## Purpose

CLI 完整化（design 03 §2.4）：`--format` 四种机器可读输出（sarif/checkstyle-xml/json/junit-xml + console 默认）、`match`/`test` 子命令、`--max-warnings`、`--rules` 覆盖。`--fix-dry-run`/baseline/`--profile` 已在 items 18/25/27 落地（不在本 plan 重复范围）。

## Current Baseline

- `NopLintCli`（nop-lint-core cli 包）：`check` 子命令全参数面（profile/fix/baseline 族）+ exit codes 0/1/2（TestNopLintCliExitCodes 钉死）；`ConsoleReporter` 人类可读输出。
- v1 裁定排除面（item 18）：`--max-warnings`、`--rules`、`--format`、match/test 子命令——本 plan 全量承接。
- exit 语义现状：0 无违规；1 error 级违规或 baseline stale（item 27）；2 内部错误。
- `RuleTestRunner`（test 子命令的执行体）与 SourcePattern.matchIn（match 子命令执行体）均已存在。

## Goals

1. `--format console|sarif|checkstyle-xml|json|junit-xml`：四个新 Reporter（与 ConsoleReporter 同接口位），输出到 stdout；`--format` 与 fix 流正交（报告描述最终磁盘内容语义保持）。
2. `match` 子命令：`nop-lint match <pattern> <file>` —— 编译 pattern 并对单文件匹配，输出命中（规则作者调试面；design 03 §2.4 的作者体验位）。
3. `test` 子命令：`nop-lint test <suites-path>` —— 跑 RuleTestRunner 套件，输出结果摘要 + exit（green=0，红=1，加载错误=2）。
4. `--max-warnings N`：warning 级诊断超 N → exit 1（error 语义不变）。
5. `--rules <id,id,...>`（R1 3.2 位点与语义裁定）：实现位点 = `RuleSetLoader.loadRuleSet` 之后、`verifyRuleLanguages` 之前过滤（**显式 --rules 是刻意收窄：某语言规则被全量过滤后不再触发未绑定语言检查**——与 v1 防静默的语义相反是有意裁定）；未知 id fail-closed（过滤前校验）；`--rules` × `--fix` × baseline 组合合法，baseline fingerprint 消费跟随过滤后残差（增注落档）。
6. 退出码契约保持：0/1/2 语义 + 新增 max-warnings 触发的 1。

## Non-Goals

- 不做 `--watch`/incremental 面（item 41/43）
- 不做 SARIF 2.1.0 全量特性（v1：runs/results/artifacts 最小面，schema 合规即可）
- 不改 check 管线语义（Reporter 只读诊断流）

## Key Decisions（执行前裁定，审查确认）

1. **Reporter 接口位（R1 3.5 统一）**：新增 `Reporter` 接口 `render(CheckOutcome, Writer)`；CLI 传 stdout Writer、测试传缓冲（golden 断言对机器格式；ConsoleReporter golden 字节级不变——PrintStream→Writer 的行分隔符行为以现有输出为准）；**机器格式不含 dry-run diff 块与 suggestion 标注**（仅诊断条目——与 fix 流正交的精确含义）；sarif severity 映射 = error→error/warning→warning/info+hint→note（R1 3.6）；junit-xml 形状 = testsuite per 文件、testcase per 诊断（name=ruleId）；`--rules` 重定义 design §4.3 的同名参数（彼处=套件路径）——owner-doc 增注点名（R1 3.7）。
2. **match 子命令（R1 3.3 补齐）**：语言解析 = 文件扩展名 → `TargetScanner.languageIdForExtension` → registry.resolve（查无 → exit 2；`--language` 可覆盖）；输出行:列 = `node.range()` + `LineIndex.lineOfByte/lineStartByte` 换算（live Match record 无 range 字段——design §1.1 旧图已过时，以本推导为准）+ 文本首行；pattern 编译失败 exit 2。
3. **test 子命令**：包装 `RuleTestRunner.runSuites(path)`；deep-suites 不在此默认面（test 子命令扫给定 path——deep 面经显式 path 可跑）；套件红 → exit 1。
4. **sarif 面**：v1 最小合规（version/drivers/results + 规则 id/severity 映射 error→error/warning→warning/message/range）；不产出 fullSchema 全字段。
