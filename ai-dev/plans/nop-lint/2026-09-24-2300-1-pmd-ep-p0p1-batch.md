## Goals

1. **枚举清单（§Execution Plan 前置表）**：14 条新规则的 id/机制/manifest credit，Phase 1 spike 后冻结（不可行者按候选池替换并回写）。
2. 14 条落地 `nop-lint-nop` 规则目录，每条 1 个 suite（valid 1 + invalid 1–2 + `.expect` 钉死）；deep 规则走 deep-suites/ + family 测试类（item 35 形态）。
3. **manifest 对账**：§D 清单逐条裁定后提升 tier→1 并补 fixture 路径；mechanism 行与 live 形态一致；manifest 头注数字更新；design 06 §7.1 增注 v2。
4. 期望集同步（编辑点清单以 Phase 2 checklist 为准）：TestProductionRuleCount→62、TestNopRuleSuites 期望集（发现数断言随期望集自动派生）、categoryOf 派生表补新 id、每条新规则 1 个 suite 指针文件、deep family production 集（若 #1 升级）。

## Non-Goals

- PMD:UnnecessaryImport/ExcessiveImports（tier 3 标"数据流分析"实为跨文件/引用计数——v1 dataflow 方法内局部+参数面不可达，留 tier 3）
- UnusedPrivateField/UnusedPrivateMethod/ImmutableField/SingularField（类成员面引用计数，v1 dataflow 方法屏障外）
- CFG 类规则（no-unreachable 等，design 05 §3 Phase 3 backlog）
- guardLogStatement/fall-through/try-with-resources 等跨语句复杂形态（关系+xscript 组合成本高、噪音风险大，留候选池后续批）
- checkstyle.xml/pmd-ruleset.xml 迁移映射（item 40）
- manifest gate 脚本重写（仅当 Phase 3 复核发现提升后校验缺口才最小修补）

## 枚举清单（14 条，Phase 1 spike 后冻结）

### A. ESLint 移植（2）
| # | id | 机制 | credit/锚点 |
|---|----|------|------|
| 1 | quality/no-constant-condition | **v1 = 字面量条件 pattern 版**：any `if ($COND)`/`while ($COND)` + 约束 $COND inList {true,false}（含括号包裹形态 spike）。**数据流升级通道 spike 裁定**：$COND 为标识符时 xscript `scope.definition` → `dataflow.constantValue(definition)` 链路可行（节点跨 binding 传递、B-1 name-anchored 陷阱）则升级 requires L3+SCOPE 深规则；不可行则字面量版定稿、数据流通道留 Non-Blocking Follow-up | ESLint no-constant-condition；design 06 §4.4 |
| 2 | quality/no-self-compare | pattern any：`$X == $X`、`$X != $X`（same-name 元变量一致性；`==` 字面量比较两操作数同名的合法场景 fixture 不设例外，头注记录） | ESLint no-self-compare |

### B. ErrorProne 正确性 P0（6）
| # | id | 机制 | credit |
|---|----|------|------|
| 3 | exception/equals-null | pattern `$X.equals(null)` | PMD:EqualsNull + EP:EqualsNull |
| 4 | quality/self-comparison | pattern `$X.compareTo($X)` | EP:SelfComparison |
| 5 | quality/self-equals | pattern `$X.equals($X)` | EP:SelfEquals |
| 6 | quality/collection-size-nonnegative | pattern `$COL.size() >= 0` | EP:SizeGreaterThanOrEqualsZero |
| 7 | exception/throw-null | pattern `throw null;`（grammar 形态 spike：throw_statement + null_literal） | EP:ThrowNull |
| 8 | quality/random-mod | pattern `$R.nextInt() % $N`；**接收者约束 spike 裁定**：$R 加名 regex（如 `random|rnd`，query-limit-required $Q regex 先例）或接受超面（任意 nextInt 接收者），头注记录 | EP:RandomModInteger |

### C. PMD 质量 P1（6）
| # | id | 机制 | credit |
|---|----|------|------|
| 9 | quality/use-collection-isempty | pattern `$COL.size() == 0`（v1 仅 == 0 形态；`!= 0`/`> 0` 变体留 follow-up） | PMD:UseCollectionIsEmpty |
| 10 | quality/string-instantiation | **收窄形态（R1 #1）**：any `new String()`（无参）+ `new String($LIT)` 且 $LIT 满约束 string 字面量（full-match regex `^".*"$`，no-sensitive-literal 先例）——`new String(byte[]/char[]/charset)` 转换形态合法不报（PMD 语义面对齐） | PMD:StringInstantiation |
| 11 | quality/biginteger-instantiation | pattern `new BigInteger($LIT)` + 约束 $LIT inList 含引号形态 `"0"/"1"/"10"`（no-md5-digest 先例） | PMD:BigIntegerInstantiation |
| 12 | exception/no-throw-npe | pattern `throw new NullPointerException()` | PMD:AvoidThrowingNullPointerException |

| 14 | quality/simplify-boolean-expression | pattern any：`$X == true`、`$X == false`（`!=` 变体 spike 后裁定入 v1 或 follow-up） | PMD:SimplifyBooleanExpressions |
