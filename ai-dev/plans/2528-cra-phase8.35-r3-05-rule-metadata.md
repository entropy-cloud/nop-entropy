## Purpose

关闭 R3-05 批的 9 项已确认 live 缺陷工单（P1×2 + P2×7；cra-index P1 open 两行 :302[W-01]/:304[W-03] live 2026-11-02 回读 open 且批次列=R3-05；P2-G80 行 :465 七成员随批收敛；P2-G81[W-11] 批前已随 R1-01 收口、P2-G82[W-06] 批前已 deferred——5.5 单元 P1/P2 台账在本批后全部收敛）+ 1 项跨 plan 显式承接面（W-02 第七面 C7-101 告警工作流实例 retention，plan 2502 裁定④ 三源一致归属 R3-05）+ G2 契约注记义务（W-28=P3 条款）。核心结果面有十：

## Risks And Rollback

- **W-01 超时预算误伤风险**：预算过低可能拒绝合法慢查询（外部大表 COUNT/剖析聚合）——默认值论证（对照 webhook 30s 惯例）+配置键覆盖为裁定①前置；socketTimeout URL 注入方案的驱动差异面（MySQL/PG/Oracle 默认值与语义差异）须论证；回滚 = 配置键缺省值单点可逆，红① 钉防「预算存在但未接线」退化。
- **W-03 钉定扩展的失效风暴风险**：逐节点 traceDepends 使依赖集从 1 行扩至 N 节点——失效检查开销随节点数线性放大（默认 5s 检查间隔下 N 大时 stat 遍历成本）+ 大规则集编辑后宽限/TTL 交互的误判面；裁定② 须量化节点数典型量级并论证检查成本；回滚 = traceDepends 扩展单点可逆，红② 钉防「扩展了但检出仍不生效」退化（plan 2500 新判据口径验证）。
- **W-05 全局态移除的兼容风险**：loginTimeout 连接属性不被部分驱动支持时建连黑洞防护回退——回退全局+WARN 分支采否为裁定④强制输入；既有 AR-02 黑洞 IP 测试面（:765 区段其余用例）零回退核对；反向钉改写的先红证据须真实（构造后全局值不变断言在未修复态必红）；回滚 = 移除单点可逆。
- **W-07 连接复用的凭证轮换风险**：DataSource 缓存键过期/配置变更后旧凭证继续使用——evict 配对（F8）为裁定⑤前置；复用连接与 W-01 超时预算叠加语义（networkTimeout 在复用连接上重复设置的幂等性）须论证；分组复用改变失败隔离粒度（同组规则共享连接——单规则连接级失败影响同组后续规则的窗口）须在裁定⑤声明；回滚 = 分组复用开关式单点可逆，红⑤ 钉防「缓存存在但未复用」退化。
- **W-08 池快照的一致性风险**：池加载上提后候选池为执行期快照——对账执行期间并发候选变更不可见（与逐行加载的现行为差异）——裁定⑥ 须声明快照窗语义；limit 值过低误拒合法候选——对照血缘 maxEdges 论证口径；回滚 = 上提单点可逆，红⑥ 钉防「复用了但计数未收敛」退化。
- **W-09 流式化的语义回归风险**：流式化改变 AR-17 部分持久化语义的触发序（逐表产出即 upsert 时 scan 中途失败的已同步表面不变，但 errors 累积时序变化）+ AR-23⑤ 故障分类路径（stream 中途 SQLException）——三既有语义零回退论证为裁定⑦前置；上限旋钮方案则须定夺超限语义（对照 maxEdges fail-fast 先例）；回滚 = read 形态单点可逆，红⑦ 变异锚定防「包络声明了但未约束」退化。
- **W-10 硬闸的误伤风险**：封顶值过低拒绝合法分析查询（同库 JOIN 明细场景）——configuredMaxQueryLimit 既有缺省论证+超限显式拒绝语义（对照跨库 truncate 先例）为裁定⑧前置；注释修正遗漏将维持契约漂移（双 owner doc 矛盾面）——修正文案在裁定⑧成文；回滚 = 闸常量/封顶单点可逆，红⑧ 钉防「注释改了但闸未落」退化。
- **W-12 分支 (b) 的行为变更风险**：异常传播整体回滚使单次执行结果丢失（结果行随事务回滚）——owner doc 声明义务为裁定⑨前置；分支 (a) 自清理与 store 事务的时序（自清理在事务内 vs 提交后补偿）须论证（事务内自清理随主回滚天然一致——removeWfRecord 同会话语义核实）；回滚 = catch 块单点可逆，红⑨ 钉防「清理写了但孤儿仍在」退化。
- **第七面 retention 的误删红线风险**：TTL 误删活跃审批实例=「审批中告警实例静默消失」（plan 2502 裁定④ 正确性红线）——终态过滤谓词+活跃实例保护断言（红⑩ 保留断言）为硬前置；nop-wf 公开 API 消费链的可达性（如终态过滤需 nop-wf 侧查询能力缺口）触发条件申报②——预设不触发论证为裁定⑩前置；回滚 = 清理载体配置禁用（retention-days=0 显式禁用档——§3.1 第 1 项）。
- **同文件多工单交叉风险**：MetaDataSourceConnectionProcessor 承载 W-01/W-05/W-07 三工单、NopMetaQualityRuleBizModel 承载 W-04/W-12 两工单（+W-07 零触碰面）、QualityAlertWorkflowProcessor 承载 W-04 兄弟/W-12/第七面三面、NopMetaQualityCheckpointBizModel 承载 W-04（+:203 运行标记零触碰面）——diff 分组登记防混（Phase 2 组 B/C 显式项），红钉逐工单独立可跑，防「A 工单修复回退时连带打红 B 工单钉」的归因混淆。
